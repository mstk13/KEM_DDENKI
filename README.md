# KEM_DENKI

株式会社ケンモチ電機の社内ツールを管理するリポジトリです。

## 概要

電気工事会社向けの業務効率化ツール群を集約・管理します。各ツールの仕様書・ソースコード・ドキュメントをここで一元管理します。

## ツール一覧

| ツール | 内容 | ドキュメント |
|--------|------|-------------|
| 入札案件管理システム | 入札案件の収集・管理・原価分析を行うWebアプリ（Streamlit + SQLite） | [docs/sepecific.md](docs/sepecific.md) |

## ディレクトリ構成

```
.
├── README.md
└── docs/                 # 各ツールの仕様書・ドキュメント
    └── sepecific.md      # 入札案件管理システム 仕様書
```
