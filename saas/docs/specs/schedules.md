# 工期管理（schedules）仕様書

バージョン: 1.0
作成日: 2026-08-02
ステータス: ドラフト

---

## 1. 概要

全現場の工期をガントチャートで一覧表示し、工程フェーズ・マイルストーン・人員配置・協力会社スケジュールを管理する。
遅延アラート（2週間前）で工期遅れを早期に検知する。

### 1.1 対象ユーザー

| ロール | できること |
|---|---|
| **社長・役員** | 全現場の工期一覧、遅延状況の把握 |
| **現場担当者** | 担当現場の工程管理、配置管理 |
| **事務** | 全現場の工期閲覧 |

---

## 2. データモデル

### 2.1 Phase（工程フェーズ）— 既存

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| site | FK → Site | ○ | 現場 |
| name | CharField(200) | ○ | 工程名 |
| start_date | DateField | | 開始日 |
| end_date | DateField | | 終了日 |
| progress | IntegerField | | 進捗率 0〜100 |
| sort_order | IntegerField | | 表示順 |
| color | CharField(10) | | バーの色（hex） |
| memo | TextField | | 備考 |

### 2.2 Milestone（マイルストーン）— 既存

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| site | FK → Site | ○ | 現場 |
| name | CharField(200) | ○ | 検査日、引渡日、申請期限など |
| target_date | DateField | | 期日 |
| completed | BooleanField | | 完了済みかどうか |
| memo | TextField | | 備考 |

### 2.3 Assignment（配置）— 既存

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| worker | FK → Worker | ○ | 作業員 |
| site | FK → Site | ○ | 現場 |
| start_date | DateField | ○ | 配置開始日 |
| end_date | DateField | | 配置終了日（NULL=無期限） |
| memo | TextField | | 備考 |

### 2.4 SubcontractorSchedule（協力会社スケジュール）— 新規

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| site | FK → Site | ○ | 現場 |
| subcontractor | FK → SiteSubcontractor | | 現場の協力会社（任意） |
| company_name | CharField(200) | ○ | 会社名 |
| work_content | CharField(200) | | 作業内容 |
| start_date | DateField | ○ | 開始日 |
| end_date | DateField | ○ | 終了日 |
| headcount | IntegerField | | 予定人数 |
| memo | TextField | | 備考 |

### 2.5 PhaseTemplate（工程テンプレート）— 新規

よくある工事パターンをテンプレートとして保存し、新しい現場に一括適用できる。

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| name | CharField(200) | ○ | テンプレート名（例: 標準電気工事、ビル新築電気） |
| description | TextField | | 説明 |
| is_active | BooleanField | ○ | 有効/無効 |

### 2.6 PhaseTemplateItem（テンプレートの工程）— 新規

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| template | FK → PhaseTemplate | ○ | テンプレート |
| name | CharField(200) | ○ | 工程名 |
| offset_days_start | IntegerField | ○ | 着工日からの開始オフセット（日数） |
| offset_days_end | IntegerField | ○ | 着工日からの終了オフセット（日数） |
| sort_order | IntegerField | | 表示順 |
| color | CharField(10) | | バーの色 |

**使い方:** テンプレートを選択 → 着工日を指定 → オフセットから各工程の日付を自動計算して Phase を一括作成。

## 4. 遅延アラート

### 4.1 ルール

- 工期終了日まで **14日以内** の現場を警告表示
- 完工・中止の現場は除外
- マイルストーンの期日が14日以内のものも警告

### 4.2 表示箇所

| 箇所 | 表示内容 |
|---|---|
| 工期管理 一覧画面の上部 | 遅延アラート一覧（残り日数付き） |
| ダッシュボード | 工期間近の現場数をバッジ表示 |
| 現場詳細の工程タブ | マイルストーンに⚠️マーク |

### 4.3 色分け

| 残り日数 | 色 | 表示 |
|---|---|---|
| 14日以上 | なし | 通常表示 |
| 7〜14日 | オレンジ | ⚠️ 要注意 |
| 7日未満 | 赤 | 🔴 緊急 |
| 超過 | 赤 + 太字 | 🔴 X日超過 |

## 5. 他アプリとの連携

### 5.1 現場管理（sites）

- 現場詳細の「工程」タブ → このアプリの現場別工程画面を表示
- 現場の start_date / end_date がガントチャートのバーになる

### 5.2 日報管理（reports）

- 配置管理で誰がどの現場にいるかを把握
- 日報入力時に配置済みの作業員をデフォルト表示

### 5.3 取引先管理（masters）

- 協力会社スケジュールで、SiteSubcontractor（現場の協力会社）を参照
- 発注先マスタから協力会社を選択可能

## 6. 技術メモ

### 6.1 新規モデル

- `SubcontractorSchedule` — 協力会社の作業スケジュール
- `PhaseTemplate` — 工程テンプレート
- `PhaseTemplateItem` — テンプレートの工程明細

### 6.2 ガントチャート描画

- CSS Grid ベース or 軽量JSライブラリ
- 月単位のスクロール
- 今日の位置に赤い縦線
- バーの色はステータス or 工程ごとにカスタマイズ
- マイルストーンは◆マークで表示

### 6.3 テンプレート適用ロジック

```
テンプレート選択 + 着工日入力
  ↓
for item in template.items:
    Phase.create(
        site=site,
        name=item.name,
        start_date=着工日 + offset_days_start,
        end_date=着工日 + offset_days_end,
        color=item.color,
    )
```
