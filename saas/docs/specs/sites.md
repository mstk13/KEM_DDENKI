# 現場管理（sites）仕様書

バージョン: 1.0
作成日: 2026-08-02
ステータス: ドラフト

---

## 1. 概要

電気工事の全業務の起点となるアプリ。現場（＝案件）の登録から完工・入金までのライフサイクルを管理する。
日報・材料・原価・工程・協力会社の情報が現場に紐づき、現場詳細画面からすべてを横断的に確認できる。

### 1.1 対象ユーザーと権限

| ロール | できること |
|---|---|
| **社長** | 全現場の閲覧・編集、収支サマリー、材料消化率の確認 |
| **役員** | 全現場の閲覧・編集、収支サマリー |
| **現場担当者** | 担当現場の閲覧・編集、日報入力、材料発注 |
| **事務** | 全現場の閲覧、請求関連情報の確認 |

## 2. データモデル

### 2.1 Site（現場）

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| code | CharField(50) | ○ | 現場コード（テナント内ユニーク） |
| name | CharField(200) | ○ | 現場名（工事名） |
| customer | FK → Customer | | 顧客（発注元）マスタから選択 |
| customer_contact_name | CharField(100) | | 案件ごとの顧客担当者名 |
| customer_contact_phone | CharField(30) | | 案件ごとの顧客担当者電話 |
| customer_contact_email | EmailField | | 案件ごとの顧客担当者メール |
| contract_type | CharField(20) | ○ | 元請 / 下請 |
| work_types | M2M → WorkType | | 工種（複数選択可） |
| status | CharField(20) | ○ | 見積中〜入金済（後述） |
| sub_status | CharField(30) | | 施工中のサブステータス（後述） |
| contract_amount | Decimal(14,0) | | 受注金額 |
| address | TextField | | 現場住所 |
| latitude | Decimal(9,6) | | 緯度（Google Maps連携用） |
| longitude | Decimal(9,6) | | 経度（Google Maps連携用） |
| start_date | DateField | | 工期開始 |
| end_date | DateField | | 工期終了 |
| manager | FK → User | | 現場担当者（社員） |
| memo | TextField | | 備考 |

### 2.2 ステータスの流れ

```
見積中 → 受注済 → 施工中 → 完工 → 請求済 → 入金済
                     │
                     └→ 中止（どの段階からも遷移可能）
```

#### 施工中のサブステータス

| サブステータス | 説明 |
|---|---|
| 着工準備 | 材料手配・人員配置中 |
| 施工中 | 通常施工 |
| 検査待ち | 中間検査 or 完了検査待ち |
| 検査中 | 検査実施中 |
| 手直し | 検査指摘の修正中 |
| 調査中 | 追加調査・現地調査中 |

### 2.3 SiteSubcontractor（協力会社）

1つの現場に複数の協力会社が紐づく。

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| site | FK → Site | ○ | 現場 |
| supplier | FK → Supplier | | 発注先マスタからの参照（任意） |
| company_name | CharField(200) | ○ | 会社名（マスタ未登録でも入力可） |
| contact_person | CharField(100) | | 担当者名 |
| phone | CharField(30) | | 電話番号 |
| work_content | TextField | | 作業内容 |
| contract_amount | Decimal(14,0) | | 契約金額 |
| memo | TextField | | 備考 |

**マスタ連携:** 発注先マスタ（Supplier）を選択すると、会社名・担当者名・電話番号が自動入力される。
マスタに無い協力会社は自由入力で登録できる。

## 4. 他アプリとの連携

### 4.1 日報（reports）→ 現場詳細の「日報」タブ

- 現場に紐づく DailyReport を日付順で表示
- ガントチャート上の日付をクリック → その日の日報を表示
- 前日/翌日のナビゲーション
- 作業員ごとの作業時間・作業内容を一覧表示

### 4.2 材料（materials）→ 現場詳細の「材料」タブ

- 現場に紐づく PurchaseOrder を表示
- 見積額 vs 発注額の消化率バー（社長・役員のみ）
- 発注一覧テーブル（発注日、品目、数量、単価、金額、仕入先）

### 4.3 原価（costs）→ 現場詳細の「原価」タブ

- 現場に紐づく BudgetItem / CostTransaction を表示
- 工種 × 原価区分マトリクス
- 社長・役員のみ表示

### 4.4 工程（schedules）→ 現場詳細の「工程」タブ

- 現場に紐づく Phase / Milestone / Assignment を表示
- 既存の schedules アプリの画面を埋め込み or リンク

### 4.5 顧客（masters）→ 現場登録時

- 顧客マスタから選択 → 住所・連絡先を自動入力
- 案件ごとの担当者名・連絡先は個別に上書き可能
- 顧客詳細画面から「この顧客の現場一覧」を見られる

## 5. Google Maps 連携

### 5.1 現場登録・編集時

- 住所を入力 → Google Geocoding API で緯度・経度を自動取得
- 地図上にピンを表示してプレビュー
- 手動でピンをドラッグして位置を微調整可能

### 5.2 地図一覧表示

- 全現場をGoogle Maps上にピンで表示
- ステータスごとにピンの色を変える（施工中=青、完工=緑、中止=赤 等）
- ピンクリック → 現場名・ステータス・担当者のポップアップ → 詳細へリンク

### 5.3 必要な設定

- Google Maps JavaScript API キーが必要
- 環境変数: `GOOGLE_MAPS_API_KEY`
- Geocoding API の有効化も必要

## 6. 技術メモ

### 6.1 新規モデル

- `SiteSubcontractor` — 現場×協力会社の中間テーブル（TenantModel継承）

### 6.2 既存モデルの変更

- `Site` に追加: `customer_contact_name`, `customer_contact_phone`, `customer_contact_email`, `contract_type`, `sub_status`, `latitude`, `longitude`, `memo`

### 6.3 ガントチャート

- フロントエンド描画: CSS Grid ベース or 軽量JSライブラリ
- サーバーサイド: Site の start_date / end_date をJSON APIで返す
- 今日の位置を赤い縦線で表示
- バークリック → 現場詳細へ遷移

### 6.4 権限制御

| 項目 | 社長 | 役員 | 担当者 | 事務 |
|---|---|---|---|---|
| 現場一覧・詳細 | ○ | ○ | 担当のみ | ○ |
| 現場の作成・編集 | ○ | ○ | ○ | × |
| 収支サマリー | ○ | ○ | × | × |
| 材料消化率 | ○ | ○ | × | × |
| 原価タブ | ○ | ○ | × | × |
| 協力会社の契約金額 | ○ | ○ | × | × |
