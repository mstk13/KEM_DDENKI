# 取引先管理（masters）仕様書

バージョン: 1.0
作成日: 2026-08-02
ステータス: ドラフト

---

## 1. 概要

顧客（発注元）と発注先（仕入先・協力会社）の2種類の取引先を管理する。
写真/PDFからのAI読み取り登録、名刺管理、取引履歴の閲覧、発注先の評価記録を行う。

### 1.1 対象ユーザー

| ロール | できること |
|---|---|
| **社長・役員** | 全取引先の閲覧・編集・評価、取引履歴の確認 |
| **事務** | 取引先の登録・編集、名刺登録 |
| **現場担当者** | 担当現場に関連する取引先の閲覧 |

### 2.3 BusinessCard（名刺）

取引先に紐づく名刺画像。写真→AI読取で自動登録可能。

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| customer | FK → Customer | | 顧客（どちらかを指定） |
| supplier | FK → Supplier | | 発注先（どちらかを指定） |
| person_name | CharField(100) | ○ | 氏名 |
| department | CharField(100) | | 部署 |
| title | CharField(100) | | 役職 |
| phone | CharField(30) | | 電話番号 |
| mobile | CharField(30) | | 携帯番号 |
| email | EmailField | | メール |
| image | ImageField | | 名刺画像 |
| note | TextField | | 備考 |

### 2.4 SupplierEvaluation（発注先評価）

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| supplier | FK → Supplier | ○ | 発注先 |
| evaluation_date | DateField | ○ | 評価日 |
| price_score | IntegerField | | 金額評価（1〜5） |
| delivery_score | IntegerField | | 納期評価（1〜5） |
| quality_score | IntegerField | | 品質評価（1〜5） |
| site | FK → Site | | 関連現場（任意） |
| comment | TextField | | コメント |
| evaluated_by | FK → User | | 評価者 |

**平均スコア:** (price + delivery + quality) / 3 で総合評価を自動計算。

## 4. AI読み取り機能（既存）

### 4.1 対応フォーマット

- 名刺の写真（jpg, png）
- 書類のPDF
- 会社案内の写真

### 4.2 抽出項目

Claude APIが以下を自動抽出してフォームに入力：
- 会社名、代表者名、担当者名
- 電話番号、FAX、メール
- 住所

### 4.3 名刺登録時

- 名刺の写真をアップロード → AI が氏名・部署・役職・連絡先を抽出
- 取引先に紐づけて保存
- 名刺画像も一緒に保存

## 5. 他アプリとの連携

### 5.1 現場管理（sites）

- 現場登録時に顧客を選択 → 連絡先が自動入力
- 顧客詳細画面の「取引履歴」タブ → その顧客の全現場一覧
- 発注先を現場の協力会社として選択可能

### 5.2 材料管理（materials）

- 材料発注時に発注先（Supplier）を選択
- 発注先詳細から発注履歴の確認

### 5.3 入札管理（bids）

- 入札案件の発注者として顧客を紐づけ

---

## 6. 技術メモ

### 6.1 新規モデル

- `BusinessCard` — 名刺管理（画像 + 抽出テキスト）
- `SupplierEvaluation` — 発注先評価（金額/納期/品質の3軸）

### 6.2 既存モデルの変更

- `Customer` に追加: `industry`, `region`, `scale`
- `Supplier` に追加: `category`, `service_description`

### 6.3 顧客コード自動採番

- プレフィックス `C` + 3桁連番（例: C001, C002）
- 発注先は `V` + 3桁連番（例: V001, V002）
