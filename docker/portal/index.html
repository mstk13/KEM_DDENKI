⚡ ケンモチ電機 — 施工コスト最適化システム
🎯 最終目標: 施工コストの最適化

入札案件の収集 → 見積もり作成 → 材料発注管理 → 実績蓄積 → AIによる見積もり自動生成・コスト予測

🗄️ データベース統合構造
┌─────────────────────────────────────────────────────────────────┐
│                    統合データベース                                │
├─────────────────────────────────────────────────────────────────┤
│  [project] 案件/現場 ← 入札管理で登録、受注後に材料管理へ引き継ぎ  │
│       │                                                         │
│       ├── [estimate_header + estimate_line] 見積もり明細   │
│       │       └── [item_master] 品目マスタ（全現場共通）   │
│       │                                                         │
│       ├── [order] 発注レコード（分割発注対応）              │
│       │       └── [supplier] 仕入先マスタ                 │
│       │       └── [receipt] 受領書                                │
│       │                                                         │
│       ├── [competitor] 競合情報                            │
│       └── [price_history] 単価履歴 → AI学習データ          │
│                                                                 │
│  入札管理(projects/costs) ←→ 材料管理(project/estimate/order) │
│  同じ案件IDで連携。入札→受注→施工の全ライフサイクルを追跡     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
データの流れ
  1. 入札管理で案件収集・見積提出
  2. 受注したら材料管理に引き継ぎ
  3. Excelで見積もり明細をインポート
  4. 発注・受領を記録し、消化率を追跡
  5. 完工後、実績データがAI学習に蓄積
  6. 次回の見積もりを自動提案
