### 構成

```
PostgreSQL ← 全アプリが共通のDBを使用
  ↑
Nginx (port 80) ← リバースプロキシで各アプリに振り分け
  ├── /bid/        → 入札案件管理 (8501)
  ├── /material/   → 材料管理 (5000)
  ├── /nippou/     → 作業日報 (8502)
  ├── /eval/       → 人事評価 入力 (8504)
  ├── /eval-admin/ → 人事評価 管理 (8505)
  ├── /eigyo/      → 営業管理 (8503)
  └── /nippou-kanri/ → 日報管理 (8510)
```
