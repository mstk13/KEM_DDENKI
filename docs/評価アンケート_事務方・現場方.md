# 人事評価アンケート（事務方 / 現場方）

`evaluation` アプリの評価項目（`evaluation/eval_items.json`）に対応した設問集です。

---

## 使い方

**回答者**：本人（自己評価）／ 上長（一次評価）／ 役員（最終評価）の3者が同じ設問に回答し、差分を面談で確認します。

**回答方法**：各設問を5段階で評価します。判断に必要な事実がない設問は「N/A（わからない・該当なし）」とし、集計から除外してください。

**5段階尺度（共通）**

| 段階 | 意味 |
|---|---|
| 5 | 期待を大きく上回る |
| 4 | 期待を上回る |
| 3 | 期待通り（標準） |
| 2 | やや不足。指導が必要 |
| 1 | 大きく不足。早急な改善が必要 |

**項目得点への換算**

```
項目得点 = （その項目の設問平均点 ÷ 5）× 項目の配点
　　　　　※小数第1位を四捨五入
```

例：「施工品質（15点）」の設問7問の平均が 4.0 → 4.0 ÷ 5 × 15 = **12点**

各項目の末尾にある「判断基準」は、5／3／1 に相当する具体的な行動の目安です。設問ごとの点数付けに迷ったときの基準にしてください。

## 第1部　共通評価項目（事務方・現場方 共通）— 40点

### 1. 勤怠・規律（10点）

> 出勤率、遅刻・早退の頻度、就業規則の遵守

**参考データ**：作業日報アプリから、対象期間の出勤日数・総作業時間・総残業時間・1日平均作業時間が自動取得されます。数値を確認したうえで回答してください。

| # | 設問 | 5段階 |
|---|---|---|
| 1-1 | 決められた始業時刻までに、業務を開始できる状態（着替え・工具準備・PC起動・朝礼参加）が整っているか | 1〜5 |
| 1-2 | 遅刻・早退・当日欠勤の際、就業規則どおりの手順で、決められた相手に、決められた時刻までに連絡しているか | 1〜5 |
| 1-3 | 有給休暇・代休の申請を、業務への影響を考慮した時期に、所定の手続きで行っているか | 1〜5 |
| 1-4 | 就業規則・社内ルール（服装、車両の使用、経費精算、SNS利用、機密保持）を理解し、日常的に守っているか | 1〜5 |
| 1-5 | 残業・休日出勤について、事前申請と実績報告を正しく行っているか | 1〜5 |
| 1-6 | 体調管理を行い、業務に支障をきたす欠勤を繰り返していないか | 1〜5 |

**判断基準**

- **5**：無断の遅刻・早退・欠勤が年間ゼロ。連絡・申請も常に期限前。他者の模範となり、周囲の規律にも良い影響を与えている
- **3**：遅刻・早退はほとんどなく、あっても必ず事前連絡がある。規則違反を指摘されたことがない
- **1**：無断の遅刻・欠勤が繰り返される。連絡が事後になる。規則違反を複数回指摘されている

**自由記述**：直近1年で勤怠・規律に関して特筆すべき事実（良い例／改善が必要な例）を、日付や状況とあわせて具体的に記入してください。

|---|---|---|

| 2-4 | 相手や緊急度に応じて手段（電話・チャット・メール・対面）を選び、要点が伝わる順序で説明できているか | 1〜5 |
| 2-5 | 顧客・元請・協力会社・官公庁とのやり取りで、当社の代表として適切な言葉遣い・態度をとれているか | 1〜5 |

- **3**：必要な報連相はできている。指示されたことの確認・報告に漏れがない
- **1**：報告がない、または遅い。トラブルが表面化してから初めて発覚することが複数回ある

**自由記述**：報連相が特にうまくいった事例／問題になった事例を1つずつ記入してください。

## 運用上の注意

### 現場方の配点が105点になっている

共通40点 ＋ 現場方固有65点（施工品質15 ＋ 安全管理15 ＋ 技術力・資格15 ＋ 工程管理10 ＋ 択一10）＝ **105点** となり、ランク表（0〜100点）と一致しません。事務方は 40 ＋ 60 ＝ 100点で整合しています。

調整案（いずれか）：

1. 現場方固有のどこかを5点減らす（例：技術力・資格 15 → 10）
2. 共通の配点を現場方だけ5点減らす
3. ランク判定を「満点に対する%」に変更する（項目編集で満点が変動しても破綻しない）

### 項目番号の重複

共通に「5. スケジュール管理」があり、事務方・現場方の固有項目も「5.」から始まっています。アンケート用紙では **共通=1〜5、固有=6以降** と通し番号に振り直すと混乱しません。

### 3者評価の運用

本人・上長・役員が同じ設問に回答し、**1段階以上ずれた設問を面談で重点的に話す**運用を推奨します。ずれの大きい設問こそ、認識合わせの価値が高い部分です。
