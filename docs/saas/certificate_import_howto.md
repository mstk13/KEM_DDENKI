# 資格証（PDF）をまとめて取り込む手順

作業員の保有資格に、資格証の PDF を添付して画面から見られるようにする手順です（ADR-0082）。

資格証は個人書類なので、**リポジトリには入れません**（このリポジトリは公開です）。
アプリが動いているPC（`desktop-rmsk0vg`）にフォルダを置いて、コマンドを1回流します。

## 1. 用意するもの

```
資格書一覧/
  釼持　政宏/
    第一種電気工事士免状.pdf
    高圧ケーブル工事技能認定証.pdf
    ...
  髙橋　翔太/
    運転免許証.pdf
  有効期限.csv        ← 期限のある資格証の日付（氏名,ファイル名,取得日,有効期限）
```

- フォルダ名が作業員の氏名。空白の有無、髙→高・釼→剣 のような字の違いは同じとみなします
- `〇〇_資格書チェックリスト.pdf` は台紙なので取り込みません
- 有効期限.csv は、期限が書かれている資格証の分だけで構いません

## 2. いちばん簡単なやり方：画面から ZIP を渡す（ADR-0091）

サーバーPCを触らずに取り込めます。

1. `資格書一覧` フォルダを右クリック →「ZIP ファイルに圧縮する」
2. アプリで **人材 → 資格証チェック → 資格証を取り込む**
3. ZIP を選んで「取り込む」。**この時点では登録されません。**
   何が登録されるかの一覧が出るので確認する
4. よければ「実際に登録する」にチェックを入れて、もう一度「取り込む」

以下は、件数が多いときや、サーバーで流したいときの手順です。

## 3. サーバーPCにフォルダを置く

エクスプローラで、フォルダごとコピーします。

| 環境 | 置き場所 |
|------|----------|
| 開発（先に試す） | `projects\KEM_DDENKI_dev\saas\import\資格書一覧` |
| 本番 | `projects\KEM_DDENKI\saas\import\資格書一覧` |

`saas\import\` は Git の管理外なので、自動デプロイで消えることも、
GitHub に上がることもありません。

## 4. コマンドを流す

まず開発環境で、何が起きるかだけ確認します（この時点では何も登録されません）。

```bash
cd "$USERPROFILE/projects/KEM_DDENKI_dev/saas"
docker compose exec web python manage.py import_certificates \
  --dir "/app/import/資格書一覧" --dates "/app/import/資格書一覧/有効期限.csv"
```

「作業員 | 資格名 | ファイル | 有効期限」の一覧が出ます。おかしなところが無ければ、
`--apply` を付けて登録します。

```bash
docker compose exec web python manage.py import_certificates \
  --dir "/app/import/資格書一覧" --dates "/app/import/資格書一覧/有効期限.csv" --apply
```

本番も同じです（`KEM_DDENKI_dev` を `KEM_DDENKI` に読み替え）。

## 5. 確認する

- 作業員一覧 → 各作業員の編集 → 保有資格（証明書管理）の「表示」から PDF が開きます
- 人材 → 資格証チェック（ADR-0081）で、添付できた資格に〇が付きます

## 6. あとから資格証を足す・差し替えるとき

同じフォルダに PDF を足して、同じコマンドを流し直せば差し替わります。
1件だけなら、画面（保有資格の編集）からアップロードするほうが早いです。

## 覚えておくこと

- 同じ資格に複数のファイルがあるときは、作業範囲の広い1枚だけ添付します
  （項目が1ファイルしか持てないため）。残りは実行結果の「同じ資格の2枚目以降」に出ます
- 資格保有一覧（ADR-0068）に無い資格名のファイルは、その作業員の保有資格を新しく作って添付します
- ファイル名の読み替えは `saas/apps/workers/certificate_import.py` の
  `FILE_TO_QUALIFICATION` に書いてあります。新しい種類の資格証を足すときはここに1行足します
