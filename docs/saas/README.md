## 現行システム（KEM_DDENKI）とSaaS版の関係

```
KEM_DDENKI（現行）          SaaS版（これから作るもの）
─────────────────          ─────────────────────────
Streamlit ベース            Django 5.2 LTS
1社専用                     100社対応（マルチテナント）
各アプリが独立DB            共有DB + company_id で分離
職種・役職をハードコード     マスタテーブルで会社ごとに定義
原価集計なし                CostTransaction で自動集計

位置づけ:
  KEM_DDENKI = 「課題が本物か」の検証（完了）
  SaaS版     = 「売り物」としての再設計
```

## 開発マイルストーン

```
M1 基盤 ◀ 今ここ
│  テナント分離・認証・マスタ・CI
│  「マンションの骨組み」
│
M2 日報＋現場
│  日報入力・承認フロー・現場管理
│  「部屋の内装」
│
M3 原価・予実管理 ← ここで初めて「売り物」になる
│  CostTransaction・自動仕訳・粗利表示
│
M4 材料（受発注）
M5 人材評価
M6 分析ダッシュボード
M7 AI連携
```
