# ADR-0058: 日報に使用材料（品名・数量・メーカー・型式・備考）を入力し、PDF の 2 枚目に出す

日付: 2026-09-14
状態: 採用

## 背景

紙の「作業日報・使用材料」（`C:\Users\Owner\Desktop\ひろき\作業日報・使用材料.pdf`）には、
使用材料品名・数量・メーカー・型式・備考の表（17 行）がある。日報の画面には使用材料を入力する欄が無く、
PDF でも ADR-0053 の改訂で作業内容の枠に材料を書くのをやめていた。
「使用材料の記入欄を日報に追加。毎日は書かないのでボタンで必要なときだけ入力欄を出し、PDF では 2 枚目に」という要望。

## 決定

### データ

`DailyReportMaterial`（日報の使用材料。既存）に列を足す（expand のみ。マイグレーション `reports/0008`）。

| 列 | 内容 |
|---|---|
| `maker` | メーカー（任意） |
| `model_number` | 型式（任意） |
| `note` | 備考（任意） |
| `quantity_used` | 数量を **空でも保存できる**ようにする（`null=True`）。材料アプリの消化率の集計は `Sum` で空を無視し、材料マスタに結び付いた行だけを見るので影響しない |

### 入力画面（日報を書く・編集）

- 「使用材料を入力する」ボタンで入力欄を開閉する。最初は閉じている（毎日は書かないため）。
  初めて開いたときは空の行を 3 つ出し、「＋ 行を追加」「削除」で増減する
- 1 行は 品名・数量・単位・メーカー・型式・備考。全部空の行は捨てる。品名が無いのに他を書いた行、
  数量が数字でない行はエラーで戻し、入力欄を開いたまま値を残す。全角の数字も読む
- 閉じても入力した内容は保存する（閉じるのは隠すだけ。消すのは行の「削除」）
- 編集では材料が入っていれば最初から開き、**画面の内容で入れ替える**。入れ替えは入力欄が送られたとき
  （`materials_submitted`）だけにし、別の経路からの保存で材料が消えないようにする。
  材料マスタに結び付いた行は `material_id` を隠し項目で持ち回り、自社の材料だけ結び付けを残す
- まとめて書いたときは、材料は現場・日単位の記録なので **最初に作られた 1 件の日報にだけ**付ける（人数分に重ねない）

### PDF

- 同じ日・同じ現場の用紙（ADR-0053）の後に、使用材料があれば **「作業日報（使用材料）」の用紙**を付ける。
  見出し（現場名・発注先・年月日・天候・工種・工程）は 1 枚目と同じ。表は参考の原本と同じ
  使用材料品名・数量（数量＋単位）・メーカー・型式・備考 の 17 行
- 材料が無ければ用紙を付けない。17 行を超えたら「（1/2）」として続ける
- 材料は同じ用紙に入る日報すべてから集める

### 詳細画面

使用材料の表に メーカー・型式・備考 の列を足す。

## 結果

- 必要な日だけボタンを押して使用材料を書け、PDF では 2 枚目に原本と同じ並びで出る
- 既存の日報・材料のデータは変わらない（列の追加と数量の空許可のみ）

## 改訂（2026-09-14 要望）

使用材料の用紙から見出し（タイトル「作業日報（使用材料）」・現場名・発注先・年月日・天候・工種・工程）を外し、
**使用材料品名・数量・メーカー・型式・備考の表だけ**にする。17 行を超えて続く用紙も表だけ。
枠の外の下余白（状態・出力日時・ページ番号）は他の用紙と同じく残す。
