# ADR-0073: 入札管理の画面で、文字をタップしてその場で直す

日付: 2026-09-16
状態: 採用

## 背景

入札管理の画面（入札案件・入札参加資格・単価マスタ・案件取得）に出ている値は、自動取得した内容が
そのまま入っていることが多く、手で直したい場面がある。これまでは「編集」ボタンから別画面のフォームを開き、
全項目のフォームを保存する必要があった。1か所だけ直したいときに手間がかかる。

プロダクトオーナーから「タップしたらその場で編集できるようにしてほしい」と依頼された（2026-09-16）。

## 決定

- 画面の値を `<span class="inline-edit" data-model=… data-pk=… data-field=…>` で出し、
  タップすると入力欄に変わる。Enter（複数行は Ctrl+Enter）または外をタップで保存、Esc で取り消す。
  選択式は選んだ時点で保存する。
- 保存は 1 つの受け口 `bids:inline_edit`（POST、JSON）に集約する。
  - 直せるモデルと項目は `apps/bids/inline_edit.py` の `EDITABLE` に書いた分だけ。ほかは 400 で断る
  - 対象は会社で絞られたマネージャ（`objects`）で引くので、他社のデータは直せない（見つからないので 404）
  - 保存は 1 項目だけのモデルフォームを通す。入力チェックはフォーム任せで、エラーはその場に赤字で出す
  - simple-history が付いているモデルは、これまでどおり履歴に残る
- 入力欄の種類（文字・複数行・数値・日付・日時・選択・はい/いいえ）は、モデルの項目から決める。
  テンプレート側は `{% inline_edit obj "field" %}` と書くだけでよい。
- 画面ごとの対象
  - 入札案件: 一覧（発注者・地域・工事種別・状態・予算額・公告日・入札期限）と詳細（案件情報と公告側の要件）
  - 入札参加資格: 自社の建設業許可・発注機関ごとの資格・全省庁統一資格（省庁別）の主な項目
  - 単価マスタ: カテゴリ・品目名・単位・単価・メモ
  - 案件取得: URL・地域・有効/無効
  - 入札ダッシュボード: 集計の表示なので対象にしない（元の案件を直せば数字が変わる）
- 一覧の案件名は詳細へのリンクのままにする（タップで開けなくなるため）。名前は詳細画面で直す。

## 結果

- 1か所だけ直したいときに、別画面へ移らずに直せる
- 直せる項目を `EDITABLE` に足すだけで、ほかの画面にも同じ仕組みを広げられる
- これまでの「編集」ボタン（別画面のフォーム）はそのまま残る
