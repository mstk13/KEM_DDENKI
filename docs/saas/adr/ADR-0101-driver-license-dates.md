# ADR-0101: 運転免許証の取得日・有効期限を入れる

日付: 2026-09-18
状態: 採用

## 背景

資格証を取り込むと取得日・有効期限も入るようにした（ADR-0095・0096）。しかし
運転免許証だけは日付が入らない。券面の有効期限は**色の帯に白抜き**で印刷されており、
OCR が文字として拾えないためである（実測：期限のある12件のうち読めなかった4件は
すべて免許証）。

プロダクトオーナーから「資格証が登録されているのに取得日と有効期限が入っていない人へ、
交付日を取得日、『〇年〇月〇日まで有効』を有効期限として入れてほしい」と
依頼された（2026-09-18）。対象は「運転免許証」と「普通自動車第一種運転免許証」。

## 決定

- 券面を人が読んだ日付を `apps/workers/license_dates.LICENSE_DATES` に置き、
  そこから入れる。OCR の読み違いで期限がずれるより、確かめた値を置くほうが安全。
  - 資格書一覧にある12名分（2026-09-18 時点）を登録した
  - 交付日 → 取得日、「〜まで有効」→ 有効期限
- 入れるのは**空いているところだけ**。既に入っている日付は上書きしない。
- **資格証（証明書ファイル）が付いている資格にだけ**入れる。
  券面を確かめずに日付だけ入れると、後から証明できない。
- 「運転免許」を含む資格名を対象にする。ただしクレーン・デリック運転士免許証や
  フォークリフトは車の免許ではないので外す。
- 氏名は空白・旧字の違いを無視して合わせる（髙橋＝高橋、釼持＝剣持）。
- 反映は次の2通り。
  - データ移送 `workers/0023_license_dates`（デプロイで1回流れる）
  - 管理コマンド `fill_license_dates`（`--apply` で登録。既定は確認のみ）
- 券面の日付が手元に無い人は「日付がまだ」として報告に出す。
  新しい人が入ったら、券面を見て `LICENSE_DATES` に足す。

## 結果

- 免許証の期限が台帳に入り、期限切れの警告が効くようになった
- 誤った日付は入らない（人が券面を読んだ値だけを入れる）
- 新しい人の免許証は、券面を見て表に1行足せば入る
