# ADR-0015: 見積もり/実経費を現場詳細に統合し、顧客名を自由入力にする

## ステータス

承認

## コンテキスト

1. 現場の見積もり/実経費を見るには `costs:list` → 現場を選ぶ、という別系統の
   導線しかなかった。現場詳細（`sites:detail`）を見ている人が、その現場の
   消化状況を知るために画面を移る必要があった。
2. 現場の顧客は `SiteForm` の FK プルダウンで選ぶ形になっており、**顧客マスタに
   登録済みの会社しか選べなかった**。マスタに無い会社を現場に紐づけるには
   「取引先 → 顧客 → 登録」→「現場 → 編集 → 選択」の2画面の往復が要る。
3. 画面上の呼称が「得意先」と「顧客」で混在していた（サイドバーは「顧客」、
   モデルとテンプレートは「得意先」）。

## 決定

### 1. 見積もり/実経費は現場詳細にセクションとして統合する

`sites:detail` に「見積もり/実経費」カードを追加し、KPI（見積もり合計・実経費
合計・消化率・粗利率）と区分別テーブルを出す。詳細画面（`costs:detail`）へは
リンクで飛べるようにし、既存画面は残す。

**タブではなくカードにした**のは、このアプリにタブ UI が一つも無いため。
ここだけ独自のタブ機構を入れると他画面と操作感がずれ、JS も増える。

### 2. 原価は必ず costs と同じ権限判定を通す

現場詳細は `@login_required` だけで全社員が開ける。一方 `costs` モジュールは
社長・役員・developer・社員番号 G 始まり・`CostAccessGrant` に限定されている。

統合にあたり、`has_module_permission(user, "costs", "read")` を通してから
金額を出す。**権限が無い場合はテンプレートで隠すだけでなく、コンテキストにも
載せない**（`total_cost` / `budget_total` / `gross_profit` / `margin_rate` を落とす）。

なおこの統合以前から、現場詳細の「原価サマリ」カードが原価合計・粗利を
**権限チェックなしで全社員に表示していた**。統合と同時にこのカードも同じ
判定の内側へ入れた。挙動の変更になるが、costs 側の制限と矛盾した状態を
残すほうが問題が大きいと判断した。

### 3. 現場の顧客欄は自由入力にする

`SiteForm.customer`（FK プルダウン）を `customer_name`（テキスト + `datalist`）に
置き換える。保存時に `sites.services.resolve_or_create_customer()` が

1. 空欄 → 顧客なし
2. 既存顧客に引き当たる → その顧客に紐づける
3. 引き当たらない → **顧客マスタに登録して**紐づける

**取り込み（`find_customer_by_name`）が自動作成しない方針と矛盾しない。**
あちらが作らないのは、機械が読み取った宛名の表記ゆれで重複マスタが増えるため。
ここは人が明示的に打った名前なので事情が違う。ただし重複を作らないよう、
引き当ては**取り込みと同じ正規化キー**（`normalize_company_name`）で行う。
「株式会社ABC」と「(株)ABC」は同じ顧客に寄る。

この結果、取り込み確認画面でも顧客名を打てるようになった。ただし読み取った
宛名を初期値に入れることはしない（入れると確定時に機械が読んだ表記のまま
マスタができてしまう）。引き当てできたときだけ、その顧客名を初期値にする。

顧客コードは `C0001` 形式で空き番号を採番する（`(company, code)` が一意のため）。

### 4. 呼称は「顧客」に統一する

`得意先` を `顧客` に置換する。モデルの `verbose_name` も変えるため
マイグレーションが出るが、**すべてメタデータのみでスキーマ変更は無い**
（masters / materials / sites / estimation の4本）。

既存マイグレーションファイルは履歴なので書き換えない。

## 影響

- 現場詳細で原価が見える範囲が**狭くなる**。従来 原価合計・粗利が全社員に
  見えていたが、今後は costs の権限を持つユーザーのみ。必要な人には
  `costs:access_list` から個別に許可を出す
- 顧客マスタが人の入力で増えるようになる。表記ゆれは正規化で寄せるが、
  まったく別表記（略称など）は別レコードになる
- サイドバーの「現場見積もり/実経費」は権限が無いユーザーにも表示され、
  押すと `PermissionDenied` になる。これは統合前からの挙動で、今回は変えていない
