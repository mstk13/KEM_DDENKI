# ADR-0097: 作業員の画面から取り込んだ資格は、資格名をファイル名にそろえる

日付: 2026-09-18
状態: 採用

## 背景

作業員の画面の「資格書を取り込む」（ADR-0094）は、ファイル名から資格保有一覧（ADR-0068）の
資格名に読み替えて添付していた。たとえば `第二種電気工事士免状.pdf` は
「電気工事士　2種」に入る。

プロダクトオーナーから、取り込んだときに次のようにしたいと依頼された（2026-09-18）。

- 資格名をファイル名に直す
- 取得日・有効期限があれば登録する
- 証明書の PDF も登録して「表示」で見られるようにする
- 登録されていない資格なら新しく登録する

資格保有一覧の名前（Excel の見出し）は略記で、資格証に印刷されている正式名称と違う。
台帳を資格証と突き合わせるときは、正式名称のほうが分かりやすい。

## 決定

作業員の画面から取り込んだときは、次のようにする。

- **資格名はファイル名（拡張子を除く）にそろえる。**
  - ファイル名と同じ資格があれば、そこに入れる
  - 読み替え表や近い名前で当たった資格は、**名前をファイル名に直してから**入れる。
    新しく作らないので、同じ資格が二重に並ばない
  - どれにも当たらなければ、その名前で新しく資格を作る（区分は名前から決める）
- 取得日・有効期限は、CSV → 証書の読み取り（ADR-0095・0096）の順で入れる。
  読み取れなければ空のままにする。
- 証明書の PDF はこれまでどおり添付し、一覧の「表示」で開ける。
- 区分は、既にある資格のものを変えない。人が直した区分を上書きしないため。
- 名前を直した資格と、新しく作った資格は、取り込んだあとに画面へ出す。

ZIP でまとめて取り込む道（ADR-0091）は、これまでどおり資格保有一覧の名前を使う。
全員分を一度に入れる用途で、資格証チェックの列が変わると見比べにくくなるため。

## 結果

- 資格証の正式名称がそのまま台帳に載る
- 同じ資格が二重に並ばない（当たったものは名前を直して使い回す）
- 一覧に無い資格証（ガス可とう管接続工事監督者など）も、選ぶだけで登録できる
