# ADR-0056: 日報の編集画面を日報を書く画面と同じ形にする

日付: 2026-09-14
状態: 採用

## 背景

日報を書く画面（ADR-0041）は、上の行に自分（時間変更の欄つき）、「作業員の日報をまとめて書く」で
左右 2 列の作業員一覧を開く形になった。一方、編集画面は作業員の欄が在籍者全員のチェックボックスを
縦に並べただけで、時間変更の欄も無く、案内文も古いまま（「社員番号が E・T で始まる方のみ…編集では1人だけ選べます」）だった。
「日報管理の編集画面は日報を書くと同じ画面が表示されるように」という要望。

## 決定

- 編集画面の作業員の欄を、日報を書く画面と同じ部品で出す。
  - 上の行は **この日報の作業員**（チェック済み・時間変更の欄つき）。ログインした人ではない
    （他人が書いた日報や、代表者がまとめて書いた日報を開くことがあるため）。退職していても候補に残す
  - 「作業員の日報をまとめて書く」で左右 2 列の一覧を開き、他の作業員を足せる（最初は閉じている）
  - 見出しは区別のため「日報を編集」のまま。PDF・削除・一緒に作った人への反映（ADR-0041）の欄も従来どおり
- 保存のしかた
  - この日報の作業員が選ばれていればその人、外されて別の人が選ばれていれば最初に選ばれた人を
    **この日報の作業員**にする（従来の「作業員を選び直す」と同じ）
  - 残りの選ばれた人には **同じ内容の日報を新しく作る**。この日報と同じ組（batch）にし、組が無ければ作る
  - 上の行の時間変更はこの日報に使い、足した人には画面の共通の時間を使う（人ごとの時間変更があればそれ）
  - 足した日報は承認済みにしない（承認は労務費の計上を伴うため）。この日報が承認済みで下書き保存したときは下書き
  - 同じ現場・日付・工種の日報が既にある人は作らず、警告を出す
- 「編集では作業員は1人だけ」の検証（`clean_workers`）を外す。

## 結果

- 書くときと直すときで同じ画面になり、編集から作業員を足すこともできる
- モデル・マイグレーションの変更なし
