# ADR-0068: 資格保有一覧の資格を、作業員ごとに資格名だけ登録する

日付: 2026-09-15（2026-09-16 改訂: 原本を Excel にし、資格名を Excel の表記に入れ替える）
状態: 採用

## 背景

会社の「資格保有状況一覧」（2026/9/15、14 人）をもとに、作業員ごとの保有資格を登録したい。
原本の写真はあとから作業員の画面で添付するので、まずは資格名だけ入れておくよう依頼された（2026-09-15）。
原本はスキャン画像で、本番のデータベースは開発の端末から直接読めない。

## 改訂（2026-09-16）

プロダクトオーナーの指示で、原本を PDF の「資格保有状況一覧」から Excel「資格保有一覧.xls」に変えた。
資格名は **Excel の見出しのまま**にする（「電気工事施工監理技士　１級」「高所作業車・作業床高⒑ｍ以上」など）。
前に PDF から登録した資格名（「施工管理技士」に直したもの）は消して、Excel の表記で入れ替える（`workers/0019`）。

- `apps/workers/listed_qualifications.py` は Excel から機械的に書き出す（14 人・150 件、○の位置は Excel と同じ）
- 見出しの「(補△)」は凡例なので資格名からは外し、「△」の人だけ「（補）」を付ける
- 消すのはこの一覧から登録した資格だけ（備考が一致するもの）。手で登録した資格・写真を添えた資格は残す
- シート「ダイト空調 資格保有一覧」は他社なので登録しない

## 決定

- 原本を読んで `apps/workers/listed_qualifications.py` に書き写す（14 人、150 件）。
  表の「○」は罫線とマスの濃さでも検出し、目視と突き合わせた。
  - 区分は原本の見出しに合わせる（免許・免状→免許、技能講習修了証→技能講習、特別教育修了証→教育・特別教育、その他→その他）
  - 資格名は原本の見出しの文言。「施工監理技士」は「施工管理技士」の書き誤りとして直す（「監理技術者」は正しい）
  - 「△」（電気工事施工管理技士 1級 の「補△」）は「電気工事施工管理技士 1級（技士補）」
- 登録先は保有資格（`WorkerQualification`、証明書画像を添付できる「保有資格（証明書管理）」の欄）。
  資格名・区分と、備考「資格保有状況一覧（2026/9/15）から登録。原本の写真は未添付」だけ入れる。
- 作業員は氏名で探す。空白の有無と、髙→高・榮→栄・釼→剣 などの字の違いは同じとみなす。
  同姓同名が複数いれば在籍中の人、それでも複数なら登録しない。同じ資格名が既にあれば登録しない。
- データ移送（`workers/0018`）で一度登録する。登録先は会社名「ケンモチ電機」、無ければ唯一の会社。
- 作業員が見つからなかった氏名は、管理コマンド `register_listed_qualifications`（既定は確認だけ、`--apply` で登録）で確かめ、
  作業員の氏名を直してから登録し直せる。

## 結果

- 反映後、各作業員の「保有資格（証明書管理）」に資格名が並び、「編集」から原本の写真・取得日・有効期限を入れられる
- 作業員名簿の「保有資格・教育」のタグ（`Worker.skill_tags`）は変えない
