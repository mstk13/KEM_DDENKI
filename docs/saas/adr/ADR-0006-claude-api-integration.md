# ADR-0006: Claude APIによるコスト最適化・工程提案

## ステータス

承認

## コンテキスト

Phase 1のML予測（LightGBM）は数値予測に特化しているが、
「なぜ超過するか」「どう対処すべきか」の分析・提案は従来MLでは困難。
LLMを活用して人間が理解しやすい形で提案を行う。

## 決定

1. **Claude API**（Haiku/Sonnet）を使用してコスト最適化提案・工程提案・リスク分析を行う
2. **Haikuをデフォルト**とし、複雑なケースのみSonnetを使用（ユーザーが選択可能）
3. ML予測結果をプロンプトに含め、LLMの分析材料とする
4. 全呼び出しをAILogに記録し、API費用を追跡する
5. JSON構造化出力を徹底し、パース失敗時は生テキストをフォールバック表示する

## 理由

- Haikuは1リクエストあたり約0.01-0.03円と低コスト
- 構造化出力（JSON）により、テンプレートでの表示が安定する
- ML予測の数値 + LLMの解釈・提案、という役割分担が明確
- APIキーは既に.envで管理済み（anthropic依存も追加済み）

## 影響

- `apps/ai/services/llm_advisor.py` を新規追加
- 3つのビュー追加: コスト最適化、工程提案、工程リスク分析
- ANTHROPIC_API_KEY の設定が必須（未設定時はエラーメッセージを表示）
