# ADR-0059: 作業員の社会保険（健康保険・年金保険・雇用保険）

## ステータス

採用（2026-09-14）。ADR-0057（作業員の現住所・緊急連絡先・健康）の続き

## コンテキスト

プロダクトオーナーの依頼（2026-09-14）: 作業員の編集に、健康保険・年金保険・雇用保険を記入する欄を作る。
適用除外の選択肢をあらかじめ用意し、雇用保険は加入している場合に番号を入れる欄を作る。

回答（同日）:

| 問い | 回答 |
|---|---|
| 誰が見て直せるか | **管理者・事務員・本人だけ**（ADR-0057 の現住所・緊急連絡先と同じ） |
| 雇用保険の番号 | **被保険者番号の下4桁だけ**（番号全体は持たない） |
| 選択肢 | 建設業の作業員名簿（全建統一様式 第5号）の書き方に合わせる |

## 決定

### 1. 項目と選択肢（`workers.Worker`）

| 項目 | 選択肢 |
|---|---|
| 健康保険 `health_insurance` | 健康保険組合・協会けんぽ・建設国保・国民健康保険・**適用除外** |
| 年金保険 `pension_insurance` | 厚生年金・国民年金・受給者・**適用除外** |
| 雇用保険 `employment_insurance` | 加入・日雇保険・**適用除外** |
| 雇用保険の被保険者番号（下4桁）`employment_insurance_number_last4` | 雇用保険が「加入」のときだけ |

- どれも空欄（未入力）で保存できる。まだ確かめていない作業員を「適用除外」と区別するため
- 雇用保険が「加入」なら、番号の下4桁（数字4つ）を**必ず**入れる。全角の数字も受け付けて半角にする
- 雇用保険が「加入」以外になったら、番号は消す（使わない番号を残さない）

### 2. 見られる人

ADR-0057 と同じ `can_view_worker_private`（社長・管理者（Y）・事務員（office_staff）・Developer・本人）。
見られない人のフォームからは欄ごと外し、送られても保存しない。詳細画面にも出さない。

### 3. 画面

- 作業員の編集: 「緊急連絡先」と「健康」の間に「**社会保険**」の区切りを置く。番号の欄は、雇用保険で「加入」を選んだときだけ出す
- 作業員の詳細: 「現住所・緊急連絡先・社会保険・健康」のカードに、健康保険・年金保険・雇用保険（加入なら「加入（番号 下4桁: 1234）」）を出す

## 捨てた選択肢

- **番号全体（11桁）を持つ**: プロダクトオーナーが下4桁だけと決めた。作業員名簿でも求められるのは下4桁
- **「未加入」の選択肢を置く**: 作業員名簿の書き方に合わせた。未入力は空欄で表す
- **加入状況は全員に見せ、番号だけ絞る**: プロダクトオーナーが、住所などと同じ扱いにすると決めた

- マイグレーション: `workers` に項目を追加するだけ（既存の作業員は空欄のまま）

  `tests/test_worker_social_insurance.py`（新規）
