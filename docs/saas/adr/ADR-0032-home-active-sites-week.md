# ADR-0032: ホームを「施工中の現場と今週の工程」に絞り、受注金額は原価を見られる人にだけ出す

## ステータス

採用（2026-09-10）

## コンテキスト

要求定義 v2 の未決事項 D8「ホームに載せる KPI」は、入札・営業・原価・書類アラートの
どれをホームのウィジェットにするかを決めていなかった（AC-4: ダッシュボードの統合は
D8 が決まってから行う）。2026-09-10、プロダクトオーナーが次のとおり決めた。

> ホームは「施工中の現場と今週の工程」を出す。金額は原価を見られる人にだけ出す。

調べた現状:

| | 内容 |
|---|---|
| ホーム（`core.views.dashboard`） | 件数カード4枚、「施工中の現場」表（先頭5件、現場名/顧客/工期/**受注金額**）、最近の日報10件 |
| 受注金額 | **全員に見えていた**。現場詳細では ADR-0015 で原価と同じ判定（`has_module_permission(user, "costs", "read")`）に閉じてある |
| 工程 | `schedules.Phase`（開始日・終了日・進捗%）、`Milestone`（目標日・完了）。現場ごとの工期詳細画面 `schedules:detail` はあるが、ホームからは見えない |
| 他のダッシュボード | 入札（`bids:dashboard`、「入札案件」の画面上部タブ。ADR-0029）、営業（「業者名鑑」の画面上部タブ。ADR-0029）、AI利用状況（「設定」配下、ADR-0026）、書類アラート（「ヒト」グループの項目） |

## 決定

1. ホームの「施工中の現場」表を、**「施工中の現場と今週の工程」**セクションに置き換える。
   現場ごとにカード1枚で、現場名（現場詳細へ）・顧客・工期・今週の工程（名前・期間・進捗）・
   今週のマイルストーン（名前・目標日・完了）・「工程を見る」（工期詳細へ）を出す
2. 「今週」は基準日を含む**月曜〜日曜**。工程は週と1日でも重なるもの（先週から続く工程も出す）、
   マイルストーンは目標日が週内のもの。開始日・終了日の片方でも無い工程はガントと同じく出さない
3. 現場は工期終了が近い順（未設定は最後）、同日なら現場名順。**最大10件**で、超えた分は件数と
   現場一覧へのリンクを出す
4. **受注金額は `has_module_permission(user, "costs", "read")` が真の人にだけ出す**。新しい判定は
   作らず、現場詳細と同じ関数を通す。権限が無い人にはテンプレートで隠すだけでなく、
   サービスの戻り値（=コンテキスト）にも金額を載せない
5. 集計はサービス関数 `schedules.services.get_active_sites_with_week_schedule(company, ref_date, limit, include_amounts)`
   に置く。基準日を引数で受ける（テストを日付に依存させない）。現場・工程・マイルストーンの
   3クエリで、現場数に比例して増えない
6. 件数カード4枚と最近の日報はそのまま残す

あわせて、ホームの「今日」を `timezone.now().date()`（UTC の日付）から `timezone.localdate()` に
直した。日本時間 0〜9 時に「本日の日報」が前日の件数になっていたため。

## 統合しないもの

D8 は「どの KPI をホームに載せるか」の決定であり、既存のダッシュボードをホームに吸収する
決定ではない。次の画面はホームに混ぜず、今の場所から開く。

| 画面 | 置き場所 | ホームに入れない理由 |
|---|---|---|
| 入札ダッシュボード | 入札案件の画面上部タブ（ADR-0029） | 見る人（営業・役員）が限られ、現場の週次の動きとは別の周期 |
| 営業ダッシュボード | 業者名鑑の画面上部タブ（ADR-0029） | 同上 |
| AI利用状況 | 設定 | 管理者向け（ADR-0026） |
| 書類アラート | ヒト | 作業員台帳の文脈で処理する。ホームの通知導線は現場モード（Phase 1-3）で扱う |
| 原価超過・予実 | 現場見積もり/実経費 | 金額の塊で、権限の出し分けをホームに持ち込むと画面が人によって大きく変わる |

## 捨てた選択肢

- **表のまま工程列を足す**: 1現場に工程が複数あると行が伸び、スマホでは横スクロールの中で
  さらに縦に読むことになる。カードで積む方がスマホ幅（375px）で読める
- **金額の列を CSS やテンプレートだけで隠す**: HTML ソースやコンテキストに残る。現場詳細
  （ADR-0015）と同じく、判定が偽ならデータ自体を渡さない
- **現場担当者（`Site.manager`）の現場だけに絞る**: 事務所側（社長・役員・事務）は全現場を見たい。
  担当現場に絞った表示は現場モードのホーム（仕様書 §9 決定③）で行う
