# ADR-0095: 資格証から取得日・有効期限を読み取って登録する

日付: 2026-09-18
状態: 採用

## 背景

資格証の取り込み（ADR-0091・0094）は、証明書のファイルを保有資格に添付するだけで、
取得日・有効期限は別に用意した CSV（有効期限.csv）でしか入らなかった。
プロダクトオーナーから「取り込んだときに取得日・有効期限があれば登録してほしい」と
依頼された（2026-09-18）。

資格証には「交付年月日」「修了年月日」「有効期限」が必ず書かれている。
PDF に文字が入っていれば、そこから読み取れる。

## 決定

- `apps/workers/certificate_dates.py` に読み取りを置き、
  作業員の画面からの取り込みと ZIP の取り込みの両方で使う。
- 拾い方
  - 取得日の見出し … 交付年月日／交付日／交付／修了年月日／修了日／認定年月日／取得年月日／合格年月日
  - 有効期限の見出し … 有効期限／有効期間／「〜まで有効」
  - 和暦（令和・平成・昭和）と西暦の両方、`2031.03.31` のような区切りも読む
  - 運転免許証の「2030年（令和12年）04月09日まで有効」のように、
    年と月の間に元号の言い換えが挟まる書き方も読む
  - 日が書かれていない有効期限（「2028年7月」）は、その月の末日にする
- **生年月日は取得日にしない。** 見出しとその直後の日付を先に落としてから拾う。
  資格証は生年月日と交付日が近くに並ぶので、ここを間違えると期限の警告が狂う。
- 「初回交付」と「交付」のように見出しが何度も出るときは、**新しいほうの日付**を使う
  （監理技術者資格者証）。
- CSV で渡された日付があれば、そちらを優先する。人が確かめた値のほうが確かなため。
- 読み取れなければ空のままにする。推測では入れない。

## 読み取れないもの

台紙ごとスキャンした**画像だけの PDF**（今ある資格書一覧のほとんど）は文字を持たないので
読み取れない。OCR は入れていない。入れる場合は次の追加が要る。

- Docker イメージに tesseract-ocr と日本語データ（約 50MB）
- 読み取り間違いを人が直す手当て（和暦の数字は特に間違えやすい）

当面は、期限のある資格証だけ CSV に書いて渡すか、画面から手で入れる。

## 結果

- 文字の入っている資格証は、添付と同時に取得日・有効期限が入る
- 画像の資格証はこれまでどおり。間違った日付が入ることはない
