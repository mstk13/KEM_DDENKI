# ADR-0092: 職種が IT の人にも、書類まわりの画面を開けるようにする

日付: 2026-09-17
状態: 採用

## 背景

書類まわりの3つの画面（書類アラート・資格証チェック・資格証の取り込み）は、
入口で「社員番号が Y で始まる管理者・superuser・事務員ロール」だけに絞っていた。

アプリの世話をしている職種 IT の人がこの画面を開こうとして
「アクセス権限がありません」になった（プロダクトオーナーの申告、2026-09-17）。
資格証の取り込みは IT の人が行う作業なので、開けないと仕事が進まない。

## 決定

- 作業員の**職種**（`Worker.job_title`）の名前に `IT` が含まれる人を、
  書類まわりの画面の対象に加える。
  - 「ITインフラ」のように前後が付く書き方があるので、含まれるかで見る（大文字に揃えて比較）
  - 判定は `apps/workers/views.can_manage_documents()` の1か所にまとめる。
    これまで3か所に散っていた同じ条件を集約する
- 対象の画面
  - 書類アラート（未添付の一覧）
  - 資格証チェック（ADR-0081）
  - 資格証の取り込み（ADR-0091）
- 役職やロールの仕組みは変えない。職種は人事の属性なので、
  権限そのものを職種で決める形はここだけに留める。
  広く権限を配るときは、これまでどおり権限管理（ロール・利用者リスト）を使う。

## 結果

- IT の人が資格証の取り込みと確認を自分で行える
- 条件が1か所になったので、次に開ける人を増やすときはそこだけ直せばよい
- 機能そのものの入口（`AppPermissionMiddleware` の作業員管理）は別の層なので、
  そちらで絞られている場合は権限管理から「作業員管理」を許可する必要がある
