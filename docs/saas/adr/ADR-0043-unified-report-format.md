# ADR-0043: 日報の形式を役職・社員番号に関係なく1つにする

日付: 2026-09-12
状態: 採用

## 背景

日報は社員番号の先頭で「現場作業の日報」（E・T）と「事務の日報」（G / S / A / P、
1日の勤務時間＋携わった現場ごとの作業内容）に分かれていた（`OfficeDailyReportForm`）。
実際には、どの役職の人も現場に出るし、代表の一人がその日の作業員ぶんを
まとめて書く運用になった（ADR-0041）。形式が 2 つあると、

- 事務区分の人が現場の日報を書くのに切替（`?mode=field`）が要る
- 同じ日の日報でも人によって項目が違い、一覧・集計で扱いが揃わない
- 「自分はどちらの形式か」を社員番号から覚えておく必要がある

## 決定

- `reports:create` は全員に同じ `DailyReportForm`（現場・工程・工種・作業内容・
  時間・作業員をまとめて選ぶ形式）を出す。役職・社員番号での振り分けは行わない。
- `OfficeDailyReportForm`、`office_form.html`、`is_office_reporter`、
  `OFFICE_CODE_PREFIXES`、`OFFICE_WORK_TYPE_NAME` は削除する。
- 作業員の欄の見出しは「作業員の日報をまとめて書く」。社員番号 E・T の人を
  左の列（現場）、それ以外を右の列に出す（`FIELD_CODE_PREFIXES` は残す）。
- 既に事務の形式で保存された日報（工種「事務」、1日1現場ずつ）はデータとして
  そのまま残る。編集は共通のフォームで行える。

## 結果

- 「日報を書く」を押せば誰でも同じ画面。代わりに書くときの切替が要らない
- 事務の人が 1 日に複数現場を書く場合は、現場ごとに日報を書く
  （まとめて書く画面で現場を変えて保存を繰り返す）
