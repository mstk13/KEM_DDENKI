# ADR-0103: 評価テンプレートを直せる人を広げる

日付: 2026-09-19
状態: 採用

## 背景

人材評価の評価テンプレート（`/workers/evaluations/template/`）は、
Django の `admin` グループに入っている人と superuser だけが開けた。

開発環境で直した評価項目を本番へ移すために書き出そうとしたところ、
プロダクトオーナーが「この操作にはadmin権限が必要です」で入れなかった（2026-09-19）。
`admin` グループは Django の内部的な集まりで、画面からは増やせない。

## 決定

次のいずれかに当てはまる人が、評価テンプレートを開けるようにする。

- superuser、または `admin` グループの人（これまでどおり）
- 社員番号が Y で始まる管理者（ほかの管理画面と同じ条件）
- 職種に IT を含む人（ADR-0092 と同じ。アプリの世話をするのが仕事のため）
- 役職が 社長・役員・Developer の人（人事の決めごとに関わる立場）

ふつうの作業員は開けないままにする。評価基準は人事の決めごとで、
誰でも直せる形にはしない。

## 結果

- 画面から人を増やせる条件（社員番号・職種・役職）で開けるようになった
- 書き出し・読み込み（ADR-0102）も同じ条件で使える
- `admin` グループを触らなくても運用できる
