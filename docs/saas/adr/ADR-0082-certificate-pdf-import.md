# ADR-0082: 資格証の PDF を保有資格に添付できるようにする

日付: 2026-09-17
状態: 採用

## 背景

作業員の保有資格には資格証の画像を添付できるが、項目が `ImageField` だったため
PDF を登録できなかった。実際に配られている資格証は、台紙ごとスキャンした PDF が多い。

プロダクトオーナーから「各作業員のフォルダにある資格書を、保有資格の該当する資格名の
ところに PDF で保存して見られるようにしてほしい。有効期限なども入力してほしい」と
依頼された（2026-09-17）。原本は `資格書一覧/<氏名>/<資格名>.pdf` の形で 46 件ある。

ここで問題になったのは、ファイルの置き場所である。

- このリポジトリは公開（public）で、誰でも読める
- 資格証には氏名・生年月日・住所・顔写真・免許番号が写っている
- アプリのサーバーは別PC（`desktop-rmsk0vg`）で、GitHub 経由でしか更新が届かない

## 決定

- 証明書の項目を `FileField` にし、拡張子を pdf / jpg / jpeg / png / gif / webp / heic に限る。
  項目名（`certificate_image`）は変えない。参照している画面・アラート・移送を壊さないため。
  PDF かどうかは `certificate_is_pdf` で分かるようにする。
- **資格証そのものはリポジトリに置かない。** 公開リポジトリに個人書類を入れることになり、
  Git の履歴からは実質消せないため。
- 代わりに、フォルダを読んで添付する管理コマンド `import_certificates` を用意する。
  サーバーにフォルダを置いて1回実行する運用にする。
  - `資格書一覧/<氏名>/<資格名>.pdf` を読み、氏名で作業員を、ファイル名で資格名を当てる
  - 氏名は空白の有無と旧字（髙→高・釼→剣 など）の違いを同じとみなす（ADR-0068 と同じ）
  - ファイル名 → 資格名の読み替えは `certificate_import.FILE_TO_QUALIFICATION` に書く
  - 「_資格書チェックリスト.pdf」は台紙なので添付しない
  - 同じ資格に複数のファイルがあるときは、作業範囲の広いものを優先して1件だけ添付し、
    残りは報告に出す（項目は1ファイルしか持てないため）
  - 資格保有一覧（ADR-0068）に見出しが無い資格は、その作業員の保有資格として新しく作る
  - 既定は確認のみ。`--apply` で実際に添付する
- 有効期限・取得日は、コマンドが読む CSV（氏名,ファイル名,取得日,有効期限）で渡す。
  資格証は画像なので文字を読み取れず、人が読んで作った表を渡す形にする。
  この CSV もリポジトリには置かず、フォルダと一緒にサーバーへ渡す。
- 期限の記載がある資格証（運転免許証・監理技術者資格者証・各種認定証など）だけ日付を入れ、
  期限の記載が無い修了証・免状は空のままにする（プロダクトオーナーの指示、2026-09-17）。

## 結果

- 台紙ごとスキャンした PDF を、画面の「表示」からそのまま開けるようになった
- 資格証チェックリスト（ADR-0081）の〇が、PDF を添付した資格にも付く
- 個人書類は公開リポジトリに入らない。代わりにサーバーでの実行が1回必要になる
- 資格証の置き換え（更新後の資格証）も、同じコマンドを流し直せば差し替えられる
