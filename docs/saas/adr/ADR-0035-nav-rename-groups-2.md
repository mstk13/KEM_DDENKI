# ADR-0035: サイドバーのグループ名を日報・勤怠・人材・取引先・業者に変え、材料・発注を現場管理のすぐ下に置く

## ステータス

採用（2026-09-10）。ADR-0033 のグループ名と、材料・発注の並び位置を置き換える

## コンテキスト

ADR-0033 でサイドバーを 現場 / 日々の記録 / 作業員 / 取引先 / 設定 / 開発 にした。
その後プロダクトオーナーが、4つのグループ名と材料・発注の位置を入力フォームで指定した（2026-09-10）。

| 対象 | 入力された値 |
|---|---|
| 案件（ADR-0033 で「現場」） | 現場 |
| 日々の記録 | 日報・勤怠 |
| ヒト（ADR-0033 で「作業員」） | 人材 |
| マスタ（ADR-0033 で「取引先」） | 取引先・業者 |
| 材料・発注の位置 | 現場管理のすぐ下 |

## 決定

| グループ | 項目 |
|---|---|
| 🏠 ホーム（単独） | ホーム |
| 現場 | 入札案件 / 積算案件 / 現場管理 / **材料・発注** / 工期管理 / 現場見積もり/実経費 |
| **日報・勤怠** | 日報管理 / 出社予定 / 月次サマリ |
| **人材** | 作業員一覧 / 人材評価 / 書類アラート / 人事評価3項目（役職限定） |
| **取引先・業者** | 顧客 / 発注先 / 業者名鑑 |
| 設定 | 通知・アラート / 権限管理 / 勤怠設定 / 積算マスタ / 工種マスタ / AI利用状況 / AI実行ログ / 変更ログ |
| 開発 | 開発管理 / 目安箱 |

- 項目「作業員一覧」はそのまま残す。グループ名が「人材」になり見出しとの重複は無くなったが、
  中身は作業員の台帳で「人材」グループの他の項目（評価・書類）と区別する名前として意味がある
- 画面上部のタブ（入札・積算マスタ・業者名鑑・材料・発注）と URL・権限は変えない

## 影響

- 変更: `apps/core/navigation.py`（グループ名3つ、材料・発注の並び位置）
- 変更: `tests/test_core_navigation.py`
