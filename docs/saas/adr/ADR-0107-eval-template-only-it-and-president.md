# ADR-0107: 評価テンプレートを開けるのは職種 IT の人と社長だけにする

日付: 2026-09-19
状態: 採用

## 背景

ADR-0103 で、評価テンプレートの編集を開ける人を広げた（admin グループ・superuser に加えて
社長・役員・Developer・職種 IT・社員番号 Y 始まりの管理者）。

その後プロダクトオーナーから「人材評価の評価テンプレート編集が表示される人は
職種が IT・社長のみにしてほしい。それ以外の人は見れないように」と指示があった
（2026-09-19）。

評価テンプレートは**人を評価する物差しそのもの**である。ここを直せる人が多いほど、
評価の公平さが揺らぐ。広げすぎていたのを戻す。

## 決定

`_is_eval_admin(user)` を次の2つだけにする。

- 職種名に `IT` が入る人（アプリの世話をするため）
- 役職が `社長` の人

外したのは **役員・Developer・社員番号 Y 始まりの管理者・admin グループ・superuser**。

`_is_president()` は使わない。あちらは superuser も社長として通すため、
使うと外したはずの superuser が戻ってきてしまう。

対象は3か所すべて（編集画面・書き出し・読み込み）と、人材評価の画面に出る
「テンプレート編集」ボタン。ボタンは view から同じ判定を渡す（ADR-0106 の直前に
ボタンだけ条件が古いまま残る事故が起きたため、画面側で条件を書き直さない）。

## 結果

- 評価の物差しを直せるのは社長と IT だけになった
- **superuser も開けない。** 社長の作業員登録が無い管理用アカウントで運用していると、
  この画面には入れない。必要になったら、その人に社長の役職を付けるか、
  職種に IT を付ける（コードを直さずに済む）
- 役員・Developer は見るだけもできない。評価そのもの（人材評価の一覧）は今までどおり
