# ADR-0084: 現場詳細の「材料の受発注」の項目を発注一覧に揃える

## ステータス

採用（2026-09-17）

## コンテキスト

プロダクトオーナーの依頼（2026-09-17）: 「現場詳細の中の材料の受発注と、材料・発注の
発注書登録の項目がことなるので、材料・発注のほうに項目をそろえてほしい」。

調べたところ、**入力フォームは既に同一**だった。現場詳細の「+ 発注を登録」は
`materials:create_po` を開き、発注一覧から入るのと同じ `PurchaseOrderForm` /
`materials/form.html` を使う。違っていたのは**一覧の表示項目**だった。

| 項目 | 発注一覧（`materials/po_list.html`） | 現場詳細（`sites/detail.html`） |
|---|---|---|
| 発注者 | `ordered_by`（未設定は `—`） | **無い** |
| 金額 | 見出し「合計金額」・右寄せ・`¥120000` | 見出し「金額」・左寄せ・`120000 円` |
| 状態 | `badge badge-gray` | 素のテキスト |
| 操作 | 「詳細」`btn-xs` | 「明細」`btn-sm` |
| 現場 | ある | 無い |

同じ発注書を2か所から見て別物に見えるのが問題なので、現場詳細側を発注一覧に合わせる。

## 決定

1. 現場詳細の表に **`発注者`** を足す。未設定は発注一覧と同じ `—`。
   `select_related("supplier", "ordered_by")` を足して行ごとの追加クエリを防ぐ
2. 金額・状態・操作の書式を発注一覧に合わせる（`¥` + 右寄せ、状態はバッジ、
   「詳細」`btn-xs`）。見積行には見積一覧と同じ PDF リンクも足す

**揃えないものを2つ決める。** ここが本題で、後から「揃え忘れ」として直されると困る。

3. **`区分` と `日付` は現場詳細のまま**にする。現場詳細は発注と見積を**1つの表に混ぜて**
   出している（ADR-0051。お金の流れを続けて読めるようにするため）。発注一覧は「発注日」、
   見積一覧は「見積日」だが、1列に両方を出すため見出しは「日付」でなければならない。
   `区分` バッジも、混在表で発注と見積を見分けるために必要
4. **見積行の相手先は `counterparty_name` のまま**にする。`Quotation.counterparty_name` は
   自社発行（`kind=ISSUED`）なら `customer`、それ以外は `supplier` を返すプロパティ。
   発注一覧・見積一覧に揃えて `{{ q.supplier }}` にすると、**自社発行の見積で相手先が
   空欄になる**。揃えることが目的ではなく、同じものが同じに見えることが目的

`現場` の列は足さない。現場詳細では全行がその現場のため、情報量がゼロで横幅だけ食う。

## 捨てた選択肢

- **表を発注用と見積用の2つに分ける**: 発注一覧・見積一覧とそのまま同じ形にできるが、
  ADR-0051 が1つにまとめた理由（お金の流れを続けて読む）を捨てることになる
- **見積一覧に合わせて `{{ q.supplier }}` にする**: 上記4のとおり、自社発行の見積の
  相手先が消える。**揃えた結果として表示が壊れるなら揃えない**
- **共通のテンプレート部品に切り出す**: 列の構成が違う（現場詳細は `区分` があり `現場` が
  無い、混在表で日付の見出しも違う）ため、部品にすると分岐が増えて読みにくくなる。
  2か所で完結する量なので、テストで揃っていることを固定するほうが安い

## 影響

- モデル・マイグレーション・フォームの変更なし。ビューの `select_related` とテンプレートのみ
- `tests/test_site_detail_material_columns.py` で、揃えた項目と**あえて揃えなかった2点**の
  両方を固定した。4の自社発行の見積についてはテストがあるので、`supplier` に「揃える」
  変更を入れると落ちる

## 残っている別の不具合（この ADR の範囲外）

`templates/materials/quotation_list.html` が `{{ q.supplier }}` を直接出しているため、
**見積一覧では自社発行の見積の相手先が空欄になる**。現場詳細側と逆で、あちらを
`counterparty_name` に直すのが筋。依頼の範囲外なので手を付けていない。
