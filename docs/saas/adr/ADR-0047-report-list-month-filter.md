# ADR-0047: 日報一覧を月で絞り込む

日付: 2026-09-12
状態: 採用

## 背景

日報一覧は状態（下書き・提出済・承認済）でしか絞れず、日付の新しい順に
全期間が並んでいた。日報が増えると、特定の月の日報を探すのに下まで
スクロールする必要がある。

## 決定

- `reports:list` に `?month=YYYY-MM` を足し、`report_date` の年・月で絞る。
  状態の絞り込み（`status`）と組み合わせられる。
- 画面には月の入力欄（`<input type="month">`）、前月・翌月、「今月」、
  「すべての月」を置き、表の上に「2026年9月の日報: N件」を出す。
- **指定なしは全期間**（従来どおり）。読めない値もエラーにせず全期間にする。
  既定を今月にすると、先月以前の提出済（未承認）が一覧から見えなくなり、
  承認漏れにつながるため。
- 月の読み取りは一覧側の `_parse_list_month` で行う。勤怠の `parse_month` は
  読めないと今月を返すので「指定なし＝全期間」と合わない。前月・翌月の計算は
  勤怠の `shift_month` を使う。
- 「未承認 N件」ボタンの件数は従来どおり全期間の件数（承認漏れを見つけるため）。

## 結果

- 月を選べばその月の日報だけを見られる。月送りで前後の月に移れる
- 何も指定しなければ今までと同じ一覧
