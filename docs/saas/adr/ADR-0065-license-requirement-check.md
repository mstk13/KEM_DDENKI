# ADR-0065: 公告の建設業許可・営業所の所在地の要件を、自社の建設業許可と照らす

日付: 2026-09-15
状態: 採用（ADR-0011 の資格判定、ADR-0064 の自社の建設業許可に足す）

## 背景

横田飛行場の工事の公告には「(11) 北関東防衛局の管轄区域(東京都、茨城県、栃木県、群馬県、埼玉県、千葉県、
新潟県及び長野県)内に建設業法の許可(当該工事に対応する建設業種)に基づく本店、支店又は営業所が所在すること」とある。
自社は神奈川県知事の許可なので参加できないが、判定は発注機関・業種・等級・点数しか見ておらず、理由が出なかった。

プロダクトオーナーの方針（2026-09-15）:
公告に建設業許可が書かれていない発注機関は照らし合わせない。参加資格の条件に書かれていれば必ず照らし合わせる。

## 決定

- 要件は**参加要件の本文（`BidProject.requirements`）から判定のたびに読む**（`announcement.extract_license_requirement`）。
  モデルに項目は足さない。
  - 取り込み済みの案件も、そのまま判定の対象になる
  - 公告を AI で読んだ案件（ADR-0010）も、参加要件の本文があれば同じように読める
  - 読み違いは参加要件の本文を直せば判定に反映される
- 読み取るもの（項目番号・「。」で文に切り、文ごとに見る）
  - 建設業許可: 「特定建設業の許可」なら特定、「許可を受け／を有し／に基づく」と「建設業」または「○○工事業」があれば許可。
    業種は「電気工事業」「「電気工事」」から取る。「当該工事に対応する建設業種」なら業種は空で、案件の工事種別から決める（`TRADE_ALIASES`）
  - 営業所の所在地: 「本店・支店・営業所」と「所在・有する・設置」がある文の都道府県名。「○○の管轄区域」の名前も取る
  - 「下請」を含む文は、下請に出す相手の話なので拾わない。「営業停止処分」「許可の取消し」は「許可を受け」に当たらないので拾わない
- 判定（`qualification._check_license_requirement`）は、公告に要件があるときだけ、**ほかの要件より先に**見る
  - 業種の許可が無い・有効期間が切れている・特定が要るのに一般 → 資格不足（`failed_on="license"`）
  - 知事許可の都道府県が公告の地域に無い → 資格不足（`failed_on="location"`）。
    知事許可は 1 つの都道府県の中だけに営業所があるので、許可行政庁から都道府県が決まる。大臣許可なら公告で確認と添えて通す
  - 満たせば「照合した要件」に根拠を足す。建設業許可が未登録なら要確認
- 理由は判定結果に出し、参加要件の該当項目（「建設業」と「許可」、または「本店・支店・営業所」と「所在」を含む項目）の右側にも出す
- 資格を満たす案件だけ取り込む設定（ADR-0011）でも同じ判定を使い、見送り案件に理由を残す
- 案件詳細の資格判定に「公告側の建設業許可」「公告側の営業所の所在地」を出す

## 結果

- 横田の公告は「北関東防衛局の管轄区域（…）に建設業許可に基づく本店・支店・営業所が必要ですが、
  自社は神奈川県知事の許可のため、営業所は神奈川県だけです。」で資格不足になる
- 電気通信工事業の特定建設業の許可を求める公告は、自社が一般建設業の許可なので資格不足になる
- 公告に建設業許可の記述が無い案件の判定は、これまでと変わらない
