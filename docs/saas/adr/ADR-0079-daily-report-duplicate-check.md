# ADR-0079: 同じ日に同じ人の日報が二重に入るのを止める

日付: 2026-09-17
状態: 採用

## 背景

日報は「現場・作業員・日付・工種」で一意にしている。同じ組み合わせは作れないが、
同じ人が同じ日に別の現場・別の工種で登録することはできる。1日に2現場へ行く日が
実際にあるので禁止はできないが、うっかり二重に書いた場合と見分けが付かない。

これまでは、同じ現場・日付・工種の重複だけを黙って飛ばし、
「〇〇 は同じ現場・日付・工種の日報が既にあるため作成しませんでした」と後から出していた。
プロダクトオーナーから「同日に同名の人が提出したら重複がありますと出して、
他に登録されている作業日報を見せて、どちらで登録するか選ばせてほしい」と依頼された（2026-09-17）。

## 決定

- 保存の前に `apps/reports/duplicates.find_duplicate_reports()` で
  「同じ日・同じ人の日報」を探す。現場・工種は問わない。
- 見つかったら保存せず、日報の画面に赤字で出す。
  - 既にある日報を現場・工種・状態つきで並べ、その日報へのリンクを付ける
  - 「このまま登録する」を押したときだけ保存する（`confirm_duplicate=1`）
  - 「やめる」で一覧に戻る
- 同姓同名（作業員マスタに同じ人が二重に登録されている場合）も重複として扱う。
- 編集のときは、編集中の日報そのものは重複に数えない。
- 「下書き保存」か「提出する」かは hidden（`duplicate_action`）で持ち回り、
  確認のあとも押したボタンのとおりに保存する。

## 結果

- 二重の日報をその場で気づけるようになった
- 1日に2現場へ行った日は、これまでどおり両方を登録できる
- 既にある「同じ現場・日付・工種」は保存できないままなので、これまでの案内も残す
