# ADR-0001: Django LTS のみを採用する

## ステータス
承認

## コンテキスト
10年以上の稼働を前提とするシステムであり、フレームワークの EOL によるセキュリティリスクを避ける必要がある。

## 決定
Django は LTS リリースのみを採用する。初期は Django 5.2 LTS（サポート: 2028-04-30）。
LTS の EOL 前に次の LTS へ移行する。非 LTS リリースへのアップグレードは行わない。

外部依存の追加は「10年後もメンテナが存在するか」を基準に、本 ADR と同様のレコードを書いた上でのみ許可する。

## 結果
- Django のバージョンアップ頻度が下がり、運用負荷が軽減される
- 最新機能へのアクセスは遅れるが、安定性を優先する
