# ADR-0096: 画像の資格証を OCR で読み、取得日・有効期限を入れる

日付: 2026-09-18
状態: 採用

## 背景

ADR-0095 で、資格証の PDF に入っている文字から取得日・有効期限を読むようにした。
しかし実際に預かっている資格証（資格書一覧の46件）は**台紙ごとスキャンした画像**で、
文字を持っていない。そのため日付が1件も入らなかった。

プロダクトオーナーから「PDF から読み取って各作業員の保有資格の取得日や有効期限を
登録してほしい」と改めて依頼された（2026-09-18）。画像から読むには OCR が要る。

## 決定

- PDF に文字が無いときだけ、ページを画像にして OCR（tesseract、日本語）で読む。
  文字がある PDF はこれまでどおりそのまま読む（速い・確実）。
- **間違った日付を入れないことを、読めることより優先する。**
  - 読み方を3通り試す（400dpi×1.5倍で psm6 / psm4、300dpi そのまま）
  - 3つの結果を突き合わせ、**多数決**で決める。同数で割れたら「読めなかった」とする
  - 期限切れの警告が狂うと気づけないので、1つの読み方だけは信じない
- OCR は画像のゆがみで「有効期限」を「交効期限」のように崩すことがあるため、
  見出しは「期限」だけでも拾う。
- tesseract が入っていない環境（CI など）では OCR を飛ばし、取り込み自体は動く。
  `CERTIFICATE_OCR_ENABLED=False` で止められる。
- 作業員の画面から取り込んだときは、読み取った取得日・有効期限を資格ごとに画面へ出す。
  人が見て確かめられるようにする。

## 実測（資格書一覧の46件・2026-09-18）

期限が書かれている12件のうち **8件を正しく読み取り**、**間違いは0件**。
読めなかった4件はすべて運転免許証で、期限が色付きの帯に白抜きで印刷されており、
OCR が文字として拾えない。運転免許証の期限は CSV（有効期限.csv）か画面から入れる。

## 結果

- 画像の資格証からも、取得日・有効期限が入るようになった
- 読めなかったものは空のまま。間違った日付は入らない
- Docker イメージに tesseract-ocr と日本語データ（約 50MB）が増える
