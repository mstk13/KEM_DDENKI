# ADR-0052: 圏外でアプリを開いても、写真の登録ができるようにする

## ステータス

採用（2026-09-13）。ADR-0048（圏外保存）・ADR-0051（現場写真）の続き

## コンテキスト

ADR-0048 では、圏外で開けるのは**電波のあるときに一度開いた入力画面だけ**だった。
Service Worker は画面を開いたときにしか控えを作らないため、次の2つが起きる。

- 「📷 現場写真を撮る」を電波のあるときに開いたことが無いと、圏外で写真を登録できない
- アプリのアイコンから開くと最初にホーム（`/`）を取りに行くが、ホームは控えていないので、圏外ではエラーの文字だけが出る

プロダクトオーナーの依頼（2026-09-13）: 圏外のときにアプリを開いても、写真保存の送信を作っておき、圏内に戻ったら送れるようにしたい。

## 決定

### 1. 「現場写真を撮る」を自動で控える

- Service Worker は、**インストールしたとき**と、**画面から頼まれたとき**に、次の画面を取りに行って控える
  - 未送信の入力（`/offline/`）
  - `apps/offline/pages.py` の `OFFLINE_START_PAGES` に載せた画面。今は「📷 現場写真を撮る」（`/sites/photos/new/`）だけ。
    現場を選ぶ欄があり、1画面でどの現場の写真も撮れるため（現場ごとの画面は数が多いので載せない）
- 画面の JavaScript（`offline.js`、ログイン後の全画面）は、電波のあるときに **10 分に 1 回まで**控えの取り直しを頼む。
  新しい現場や撮影場所の候補が、控えにも入るようにするため
- ログインが切れていてログイン画面へ飛ばされた応答は控えない（前の控えを残す）

### 2. 圏外でアプリを開いたら、未送信の入力へ移す

- 控えていない画面（ホームなど）を開こうとして通信できなかったら、エラーの文字の代わりに**控えてある「未送信の入力」へ移す**（`/offline/?offline=1`）
- 未送信の入力の画面に「圏外のため開けませんでした」の知らせと、**「📷 現場写真を撮る」**のボタンを置く
- 控えてある画面は今までどおり、電波があれば最新、圏外なら控えを出す。控えが無い入力画面も、未送信の入力へ移す

```
アプリを開く（/）
  ├─ 電波あり → いつものホーム。裏で「現場写真を撮る」「未送信の入力」の控えを取り直す（10分に1回まで）
  └─ 圏外     → 控えてある「未送信の入力」（圏外の知らせ）
                  └─「📷 現場写真を撮る」（控え）→ 登録 → 端末に保存 → 電波が戻ったら送る（ADR-0048）
```

### 3. 控えを取りに行くときは「登録しました」などの知らせを読まない

控えを取りに行く通信には印のヘッダ `X-Offline-Precache: 1` を付け、画面（`base.html`）はそのとき知らせを出さない。
Django の知らせは一度画面に出すと消えるので、控えが先に読むと、本来の画面（写真の一覧など）に出なくなるため。

### 4. 端末を共有したとき

- 控えにはその会社の現場名が入る。ログアウトすると今までどおり控えを消す（ADR-0048）
- ログアウトせずに別の人がログインしたときに前の人の控えが残らないよう、画面は**ログインしている人が変わったら控えを消してから取り直す**
  （誰の控えかは端末の localStorage に人の番号だけを残して見分ける）

## 使える条件（変わらないこと）

- **この版になってから、電波のあるときにアプリを一度でも開いている**こと（どの画面でもよい）。一度も開いていない端末には控えが無い
- HTTPS（`…ts.net`）で開いていること。IP を直接打つ http の URL では Service Worker が動かない
- ログインが切れているときは、圏外で保存はできるが、送るのはログインし直してから（ADR-0048 と同じ）
- iPhone はホーム画面に追加したアプリとして使う。Safari のタブのまま長く使わないと、端末の控えが消されることがある

## 捨てた選択肢

- **すべての画面を控える**: 容量が増え、原価など見せたくない画面の中身まで端末に残る。入力に要る画面だけにする
- **ホーム（`/`）も控える**: ホームは工程や参加者が日々変わり、古い中身を出すと誤解のもとになる。圏外では「未送信の入力」から入る形にした
- **Service Worker 側だけで定期的に取り直す（Periodic Background Sync）**: iPhone に無い。画面を開いたときに頼む形にした

## 影響

- 変更: `apps/offline/pages.py`（`OFFLINE_START_PAGES`）・`views.py`（控える画面と印のヘッダを Service Worker に渡す）、
  `templates/offline/sw.js`（控える・取り直し・圏外のときの移り先）、`static/js/offline.js`（取り直しを頼む・人が変わったら控えを消す）、
  `templates/offline/outbox.html`（圏外の知らせ・現場写真を撮るボタン）、`templates/base.html`（控えのときは知らせを出さない・人の番号）、
  `static/css/style.css`、`tests/test_offline_outbox.py`、README
- マイグレーションなし。新規依存なし
