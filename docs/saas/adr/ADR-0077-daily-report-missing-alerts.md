# ADR-0077: 日報を書いていない人に知らせる

日付: 2026-09-17
状態: 採用

## 背景

日報が出ていない日は、労務費が計上されず、月末にまとめて催促することになっていた。
プロダクトオーナーから「日報を書いていない人がいたら通知が行くようにしてほしい。
日報を書く画面にも赤字で〇日の日報を書いていませんと出してほしい」と依頼された（2026-09-17）。

「書いていない日」を決めるには、その人がその日に働く予定だったかが要る。
全ての平日を対象にすると、休みや現場の無い日まで催促してしまう。

## 決定

- 出社予定（`attendance.AttendPlan`）の稼働する区分（出社・現場・直行直帰・出張）が
  入っている日を「日報を書くべき日」とする。予定が無い日・休み・有休・在宅は対象にしない。
- 今日は書いている途中なので対象にしない。前日から14日ぶんをさかのぼって調べる。
- `apps/reports/missing_alerts.py` に置く。
  - `missing_reports(company)` … (作業員, 日) の並びを返す
  - `check_daily_report_missing_alerts(company)` … 本人へ1件ずつ、管理者へは日ごとに
    まとめて1件の通知を出す
  - 二重に送らないための目印は、送った通知そのもの
    （`reference_type="reports.missing:<日付>"`）。アラート履歴のテーブルは使わない
- 毎朝の `send_document_alerts` に相乗りする。cron の設定を増やさないため。
- 日報の一覧と「日報を書く」画面の上に、自分の抜けている日を赤字で出す。

## 結果

- 書き忘れた本人がその日のうちに気づける
- 管理者は日ごとに1件で全体を把握できる
- 出社予定を入れていない会社では何も出ない（予定を入れると効き始める）
