# ADR-0050: 日報一覧を現場・作業員で絞り込む

日付: 2026-09-12
状態: 採用

## 背景

日報一覧は状態と月（ADR-0047）でしか絞れず、特定の現場の日報や、特定の作業員の日報だけを
見る・PDF にする（ADR-0049）には、一覧を目で追う必要があった。

## 決定

- `reports:list` に `?site=<現場ID>` と `?worker=<作業員ID>` を足す。状態・月と組み合わせられる。
  読めない値（空・文字・0 以下）は絞らない。
- 絞り込みは一覧と一覧 PDF で共通の `_filtered_reports` に入れ、選ばれた条件は辞書で返す。
  `DailyReport.objects`（自社だけ）から絞るので、他社の現場・作業員の ID を指定しても他社の日報は出ない。
- **選択肢は、自社の日報に一度でも出てくる現場・作業員だけ**にする。現場は名前順、
  作業員は作業員一覧と同じ社員番号順（`sort_workers_by_code`）。
  登録済みの全現場・全作業員を出すと、日報の無い完了現場や事務の人まで並んで選びにくくなるため。
  退職者でも日報があれば選べる（過去の日報を探せるように）。
- 前月・翌月・今月・すべての月・「この一覧をPDF」・PDF から一覧に戻るリンクは、
  他の絞り込みを引き継ぐ。クエリはビューの `_filter_query` で組み立てる
  （テンプレートで `&` を直書きするとエスケープされず、条件の追加のたびに書き漏れが起きるため）。
- 「現場・作業員を外す」ボタンで、月は残したまま現場・作業員の指定だけを外せる。
- 件数の見出しは「2026年9月・A社ビル・電工太郎の日報: N件」のように選んだ条件を並べる。
  一覧 PDF のファイル名も同じ順（`日報_2026-09_A社ビル_電工太郎.pdf`）。ファイル名に使えない文字は `_` にする。
- 「未承認 N件」ボタンは従来どおり全体の件数・全体への絞り込み（承認漏れを見つけるため）。

## 結果

- 現場ごと・作業員ごとの日報を一覧でも PDF でも出せる
- 条件を足しても、リンクの引き継ぎは `_filter_query` の 1 か所で済む
