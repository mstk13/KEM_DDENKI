# ADR-0075: 受注までの流れの段階名・項目名・備考を、案件ごとに直せるようにする

日付: 2026-09-16
状態: 採用

## 背景

「受注までの流れ」のバーに出る段階名（参加申請・見積提出など）は、公告の別表のラベルに
含まれる語から当てている（`gantt._STAGE_RULES`）。公告の書き方は発注機関ごとに違うので、
当たらない・別の段階に当たることがある。プロダクトオーナーから
「参加申請や見積提出なども編集できるようにしてほしい」と依頼された（2026-09-16）。

ADR-0074 で日付は表からタップして直せるようにしたが、名前は直せないままだった。

## 決定

- 案件ごとの手直し（`BidProject.schedule_overrides`）に3つ足す。鍵はこれまでどおり
  公告のラベルのままにして、公告を取り直しても手直しが外れないようにする。
  - `stage`  … 段階名。バーの名前と表の「段階」に出る
  - `title`  … 表の「公告の項目」に出す見出し（鍵は変えない）
  - `detail` … 備考
- 重要日程の表で、段階・公告の項目・備考をタップして直す。保存は日付と同じ
  `bids:schedule_override`。空で保存すると、その手直しだけ取り消して公告どおりに戻す。
- 段階名を直すと、会社の既定（`BidScheduleRule`）の引き当ても新しい名前で行う。
  既定に無い名前にしたときは自動判定（開始日があれば期間、無ければ締切）になる。

## 結果

- 公告の書き方が独特で段階名が当たらない案件を、その場で直せる
- 公告の原文（`bid_schedule`）は触らないので、取り直しても手直しは残る
- 会社全体の段階の既定を変えたいときは、これまでどおり「会社の既定を編集」を使う
