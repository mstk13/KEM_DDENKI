# ADR-0003: 業種名によるコード分岐を禁止する

## ステータス
承認

## コンテキスト
KEM_DDENKI（現行システム）では「電工」「事務」等の業種固有名詞がコードにハードコードされていた。
SaaS として複数業種に対応するには、業種の違いをデータ（マスタ）で吸収する設計が必要。

## 決定
業種名（設備・電気・内装・解体）をコード・クラス名・分岐条件に**一切登場させない**。
`Company.industry_type` は参考情報としてのみ保持し、ロジックの分岐には使用禁止。

業種固有の工種は `WorkType` マスタ（階層構造）で表現する。
業種拡張 = マスタへの行追加のみ。コード変更ゼロ。

## 結果
- 新業種の追加がマスタデータの追加だけで完了する
- コードベースの業種依存がゼロになり、保守コストが下がる
- `Company.industry_type` をロジックに使った場合はコードレビューで却下する
