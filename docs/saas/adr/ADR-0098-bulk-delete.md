# ADR-0098: 一覧から選んだものをまとめて消せるようにする

日付: 2026-09-18
状態: 採用

## 背景

削除はどの画面も1件ずつのボタンしか無い。取り込み直しの後始末や、試しに入れた行を
片付けるときに数が多いと手間がかかる。プロダクトオーナーから
「削除機能がある部分すべてでまとめて削除できるようにしたい」と依頼された（2026-09-18）。

削除の入口はアプリ全体で32か所ある。画面ごとに作ると同じものを32回書くことになり、
どれかで会社の絞り込みを忘れれば他社の行を消せてしまう。

## 決定

- 受け口は1つだけ作る（`/bulk-delete/`）。画面はチェックボックスと1つのボタンを置くだけにする。
- **消せる対象は `apps/core/bulk_delete.py` の `DELETABLE` に書いたものだけ。**
  画面から任意のモデルを指定しても消せない。
- 引くのは会社で絞ったマネージャ（`objects`）。他社の行は選んでも消えない。
- 画面ごとの「消してよいか」の決まりは、その関数をそのまま使う
  （承認済みの日報は消せない、など）。消せなかったものは名前を画面に出す。
- ほかから参照されていて消せない行（`ProtectedError`）は飛ばし、名前を画面に出す。
  参照ごと消すような強い削除はしない。
- 消す前に必ず確認のダイアログを出し、件数を見せる。
- 画面側は共通の部品を読み込むだけにする。
  - 見出しに `core/_bulk_delete_head.html`（その表の全部を選ぶ）
  - 各行に `<input type="checkbox" class="bulk-check" name="ids" form="bulk-delete-form">`
  - 表の下に `core/_bulk_delete.html`（鍵と戻り先、削除ボタン）
  - 行の中にある個別の削除ボタンと入れ子にならないよう、`form` 属性で外の form につなぐ

## 入れた画面

- 日報・現場・作業員（在籍／退職）・顧客・発注先
- 入札案件・入札参加資格（建設業許可／発注機関ごと／全省庁統一）・単価マスタ・
  案件取得・見送り案件
- 作業員の保有資格・健診の記録
- 現場の工程・現場写真・提出書類のファイル
- 工期管理の工程・マイルストーン・配置
- 材料の発注明細・見積明細
- 積算の工程・案件資料・競合
- 安全書類（KY）の参加者・開発プロジェクト・人事評価の割当・営業の訪問記録
- アラートルール

日報は元から一括承認のチェック欄があるので、それをそのまま使い、
「選んだ日報を削除」を隣に足した（チェック欄を2つ並べない）。

1つの画面に表が複数あるときは、`bulk_form` で form の id を分ける。
チェックボックスは `form` 属性でその id につなぐので、
行の中にある個別の削除ボタン（form）と入れ子にならない。

## 入れていないもの

- 自社書類（tenants）… 1件ずつのカード表示で、一覧の表になっていない
- 開発タスク・積算の内訳明細 … 画面の作りが表ではなく入れ子のため、必要になったら足す

## 結果

- 一覧から選んでまとめて消せる
- 消してよいかの決まりと会社の絞り込みは、これまでと同じものが効く
- 新しい画面に足すときは `DELETABLE` に1行と、テンプレートに3か所を書くだけ
