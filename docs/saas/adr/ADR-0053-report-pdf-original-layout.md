# ADR-0053: 日報 PDF の様式を紙の「作業日報 原本」に合わせる

日付: 2026-09-14
状態: 採用（ADR-0049 の「形式」を置き換える。出し方・上限・ファイル名の方式は ADR-0049 のまま）

## 背景

ADR-0049 の日報 PDF は「日報 1 件＝ A4 1 ページ」の独自の様式だった。
現場では紙の「作業日報 原本」（`\\KRST1-19102312\Kuraemon\scan\INU\作業日報　原本.pdf`）を使っており、
「原本を参考に記入欄を追加・削除し、記入する情報はアプリの情報を維持する」よう要望があった。

原本の様式:

| 部分 | 欄 |
|---|---|
| 見出し | 作業日報 / 現場名・発注先 / 年月日（令和）・曜日 |
| 自社の作業員（15 行） | 作業員名・作業時間（開始～終了）・残業・宿泊・作業内容・使用材料（15 行を縦に結合した枠）/ 合計 人 / 交通手段等（車・電車・交通費） |
| 協力会社（3 社・3 行／2 行／2 行） | 会社名・作業員名・人数・作業時間・作業内容・承認印 / 会社ごとの交通手段（車・乗合・電車・交通費）/ 合計 人 |
| 署名 | 現場代理人又は責任者 |

## 決定

**アプリの入力画面・データは変えず、PDF の様式だけを原本に合わせる。**

### 1 枚の単位

原本は 1 枚が「1 現場 × 1 日」で、その日の作業員全員を並べる。アプリの日報は 1 件＝作業員 1 人なので、
**同じ日・同じ現場の日報を 1 枚にまとめる**（`group_reports`）。

- 一覧の PDF: 絞り込んだ日報を日付の古い順・現場名順にまとめる（絞り込みで外れた日報は入らない）
- 1 件の PDF ボタン: その日報と**同じ日・同じ現場の日報をまとめた 1 枚**を出す（状態を問わない）。
  ファイル名は `日報_2026-09-10_A社ビル新築.pdf`

### 欄とアプリの情報の対応

| 原本の欄 | アプリの情報 |
|---|---|
| 現場名・発注先 | 現場名・現場の顧客 |
| 年月日・曜日 | 日報の日付（令和。2019 年より前は西暦） |
| （追加）天候・工種・工程 | 年月日の右に並べる。同じ用紙の日報で違えば「・」でつなぐ（2026-09-14 追加） |
| 作業員名 | 作業員（社員番号順。`is_partner_worker` でない日報） |
| 作業時間 | 開始～終了（終了が翌日なら「翌」） |
| 残業 | 残業時間（0 なら空） |
| 作業内容・使用材料 | 作業内容（同じ内容は 1 回。工種・工程の違う日報が混ざるときだけ【工種／工程】を付ける）、使用材料（材料・単位ごとに合計）、その他 |
| 合計 人 | 自社の作業員の人数 |
| 協力会社: 会社名・作業員名・人数・作業時間・作業内容 | 協力会社・作業員・その会社の人数・開始～終了・作業内容 |
| 協力会社: 合計 人 | 協力会社の作業員の人数 |

- **追加（空欄のまま手書き用）**: 宿泊、交通手段・交通費（自社・協力会社ごと）、承認印、現場代理人又は責任者。
  アプリに該当する情報が無いため
- **削除（独立した欄として）**: その他・使用材料の表・通常時間・作業時間の合計・作成者。
  原本に欄が無いため。ただし情報を落とさないよう、その他・使用材料は作業内容の枠に書く
- **天候・工種・工程**: 当初は作業内容の枠に書いていたが、見やすいよう年月日の右に欄を設けた（2026-09-14 要望）
- **枠の外（下余白）**: 状態の件数（「提出済 1件・下書き 1件」）と承認者、出力日時・ページ番号

### あふれたとき

- 自社の作業員が 15 人を超えたら、同じ見出しで次の用紙に続ける（見出しに「（1/2）」）。合計人数は各用紙に全体の人数
- 協力会社は 3 社ぶんの枠に順に詰め、1 社の人数が枠の行数より多ければ次の枠・次の用紙に同じ会社名で続ける
- 作業内容の枠に入りきらない文は文字を小さくし（9pt → 5.5pt）、それでも入らなければ末尾を
  「…（以下略。全文はアプリの日報を参照）」にする。2 枚目以降の作業内容の枠は「（1 枚目に記載）」

## 捨てた選択肢

- **アプリの入力画面に宿泊・交通手段・交通費の欄を足す**: 要望は PDF の記入欄の追加・削除で、
  入力の手間とデータ（マイグレーション）が増える。必要になったら別に決める
- **1 件 1 ページのまま原本風にする**: 原本は作業員を並べる用紙で、1 人ずつでは作業員の表がほぼ空になる

## 結果

- 印刷すると紙の原本と同じ並びになり、宿泊・交通費・承認印などは従来どおり手書きできる
- `apps/reports/pdf.py` を作り直し、テスト（`tests/test_report_pdf.py`）も様式に合わせて書き直した
