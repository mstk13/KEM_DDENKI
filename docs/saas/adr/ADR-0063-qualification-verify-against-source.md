# ADR-0063: 入札参加資格を原本と照らし合わせて直すコマンド

日付: 2026-09-15
状態: 採用

## 背景

入札参加資格（`Qualification`・`UnifiedQualification`）は、Excel・PDF の取り込みや手入力で登録されている。
業者番号の先頭の 0 が落ちる、有効期限が取り込みの既定（開始日＋2年）になる、等級が全角になる、
といったずれが起きうる。プロダクトオーナーから、紙の原本「入札案件参加資格.pdf」と照らし合わせて
不備を直し、修正前と修正後を一覧で出すよう依頼があった（2026-09-15）。

原本はスキャン画像で文字が取れず、本番のデータベースは開発の端末から直接読めない。

## 決定

- 原本を目で読んで `apps/bids/qualification_source.py` に書き写す。
  一覧（1〜3 ページ、92 行、有効期限 2027-03-31）と全省庁統一資格の通知書（4 ページ、3 行、2028-03-31）。
- 原本の書き誤り・空欄・手書きの判断は同じファイルの `NOTES` に残し、コマンドの出力にも出す。
  - 財務省(北海道財務局) 電気工事の経審点「8884」は 884 の書き誤りとして 884
  - 財務省(東海財務局) の等級空欄、最高裁判所 電気通信の等級空欄、法務省 電気通信の「○」、
    経済産業省の点数空欄、国立印刷局（手書き）の総合点空欄は原本どおり
- 管理コマンド `verify_qualifications` を足す。
  - 既定は**確認だけ**（何も変えない）。`--apply` で直し、足りない行を登録する
  - 原本に無い行・重複は一覧に出すだけ。`--apply --delete-extra` のときだけ消す
  - 行の突き合わせは資格判定と同じ正規化（発注機関の括弧・空白、業種区分の末尾「工事」）。
    突き合わせた行の業種区分・等級・点数・業者番号・有効期間などは 1 文字でも違えば原本の値にする
  - 全省庁統一資格（省庁別）は、全機関で通知書と同じ等級・点数か、営業品目が同じ集合かを見る
    （区切り文字の違いだけなら直さない）
  - 変更は simple-history に理由「原本（入札案件参加資格.pdf）と照合して修正」付きで残る
- 資格の登録コマンド `seed_qualifications` の「物品の買受け」に、通知書の営業品目「その他」を入れる。

## 結果

- サーバーで `python manage.py verify_qualifications` を実行すれば、原本との違いを
  「対象 | 項目 | 修正前 → 修正後」で確認でき、`--apply` で直せる
- 原本が更新されたら `qualification_source.py` を書き換えてから実行する
