# ADR-0094: 作業員の画面から、資格証をまとめて選んで登録する

日付: 2026-09-18
状態: 採用

## 背景

資格証の取り込みは、会社ぜんぶの分をフォルダごと ZIP にして渡す形だけだった（ADR-0091）。
ふだんの運用では「この人の資格証が何枚か手元にある」ことのほうが多い。
1枚ずつ資格の編集画面を開いて添付するのは手間がかかる。

プロダクトオーナーから「各作業員の保有資格のところに資格書を取り込むボタンを置いて、
登録したい PDF をすべて選んで、それぞれの資格に登録したい」と依頼された（2026-09-18）。

## 決定

- 作業員の編集画面の「保有資格（証明書管理）」の見出しに、
  ファイルを複数選べる入力と「資格書を取り込む」ボタンを置く。表の列は変えない。
- 選ばれたファイルは、ファイル名からその作業員の保有資格に振り分ける。順に見る。
  1. 読み替え表（`FILE_TO_QUALIFICATION`。ADR-0082）にある資格名と同じもの
  2. 資格名がそのままファイル名になっているもの（「運転免許証.pdf」）
  3. 全角半角・記号・空白を落として比べ、8割以上似ているもの
- どれにも当たらないファイルは**登録しない**。取り違えると、別の資格の証明として残ってしまうため。
  画面に「どの保有資格か分かりませんでした」と出し、資格を作ってから選び直してもらう。
- 既に証明書が付いている資格に入れたときは差し替える（更新後の資格証を入れ直せるように）。
- ZIP でまとめて取り込む道（ADR-0091）はそのまま残す。全員分を一度に入れるときはそちらが速い。

## 結果

- 1人分の資格証を、まとめて選んで登録できる
- ファイル名が資格名そのままでも、証明書の正式名称でも、どちらでも振り分けられる
- 取り違えは起こさない（分からないものは人に返す）
