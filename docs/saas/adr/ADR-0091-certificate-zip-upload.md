# ADR-0091: 資格証の一括取り込みを、画面からの ZIP でできるようにする

日付: 2026-09-17
状態: 採用

## 背景

ADR-0082 で、資格証の PDF をまとめて添付する管理コマンド `import_certificates` を作った。
個人書類を公開リポジトリに置けないため、「サーバーPCにフォルダを置いて、
コンソールでコマンドを1回流す」運用にしていた。

しかし、その手順はプロダクトオーナーに負担が大きい。実際に依頼されたのは
「資格書を保有資格のところに登録してほしい」であって、サーバーの操作ではない。
また、開発者の端末からサーバーPC（`desktop-rmsk0vg`）へは
SSH も共有フォルダも通っておらず、代わりに実行することもできない。

## 決定

- `/workers/certificates/import/` に取り込みの画面を作る。事務員・管理者のみ。
  - 作業員ごとのフォルダを ZIP にして選ぶだけ。中に `有効期限.csv` があれば一緒に使う
  - 既定は**確認だけ**。「実際に登録する」を選んだときだけ添付する
  - 何が登録されるか（作業員・資格名・ファイル・有効期限）と、
    新しく作る資格・差し替え・2枚目以降・読み替え表に無いファイル・
    見つからない作業員を、そのまま画面に出す
- 取り込みの中身は ADR-0082 の `import_certificates` をそのまま使う。
  画面は ZIP を展開して渡すだけにする。コマンドも残す（大量のときはそちらが速い）。
- ZIP の展開では次を守る。
  - `../` や絶対パスを含む名前は展開しない（上の階層へ書き出させない）
  - `.pdf` と `.csv` 以外は展開しない
  - 100MB まで
  - 展開先は一時ディレクトリ。処理が終わったら消える
- ZIP の作り方で親フォルダが1枚多く入ることがあるので、
  人のフォルダが並んでいる階層まで自動で降りる。

## 結果

- サーバーPCに入らなくても、ブラウザから資格証をまとめて登録できる
- 登録前に内容を確認できるので、読み替えの間違いに気づける
- 個人書類はこれまでどおりリポジトリに入らない（アップロードされた ZIP も残さない）
- 実データ（46 ファイル）で通しの確認を済ませてある。43 件が添付され、
  期限のある 11 件に有効期限が入る
