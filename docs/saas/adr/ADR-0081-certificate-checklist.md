# ADR-0081: 資格証の提出チェックリスト

日付: 2026-09-17
状態: 採用

## 背景

資格証（証明書の画像）は作業員ごとの編集画面から登録する。未添付のものは
「書類アラート」に一覧で出るが、これは足りないものだけを並べた表なので、
「誰の何が出ていて、何がまだか」を全体で見渡せない。

プロダクトオーナーから「資格証の提出のチェックリストを作って、
登録されたら丸が付くようにしてほしい」と依頼された（2026-09-17）。

## 決定

- `/workers/qualification-checklist/`（`workers:cert_checklist`）に、
  作業員（縦）×資格名（横）の表を置く。
  - 〇 … 資格証の画像が登録済み
  - △ … 資格は登録済みだが資格証がまだ（押すとその資格の編集画面へ）
  - 空欄 … その資格を持っていない
- 横に並べる資格名は、登録のある資格名だけにする（誰も持っていない列を作らない）。
- 行ごとに「提出済 / 登録数」、画面上部に会社全体の数と未提出の件数を出す。
- 見られるのは事務員・管理者だけ。書類アラートと同じ扱いにする。
- 左メニューの「書類アラート」の下に「資格証チェック」を足す。
- 作業員一覧には列を足さない（ADR-0068 で決めたとおり、一覧の形は変えない）。

## 結果

- 資格証の提出状況を1枚で見渡せる
- 足りないところから直接、資格証の登録画面へ行ける
- 未添付の通知（`cert_missing`）と書類アラートはこれまでどおり残る
