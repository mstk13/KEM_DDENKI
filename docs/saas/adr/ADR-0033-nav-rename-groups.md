# ADR-0033: サイドバーのグループ名を現場・作業員・取引先に変え、材料・発注を現場へ、マスタ類を設定へ移す

## ステータス

採用（2026-09-10）。ADR-0029 のグループ名と配置の一部を置き換える

## コンテキスト

ADR-0029 で、サイドバーを再設計仕様書 v2.0 §2.1 の業務グループ
（ホーム / 案件 / 日々の記録 / 材料・発注 / ヒト / マスタ / 設定 / 開発）に並べ替えた。
開発環境で使ったうえで、プロダクトオーナーから次の指示があった（2026-09-10）。

| 旧 | 新 | 補足 |
|---|---|---|
| 案件 | **現場** | 入札案件・積算案件・現場管理・工期管理・現場見積もり/実経費はそのまま |
| 単独項目の「材料・発注」 | **現場グループの中へ** | 発注は現場に紐づく。材料ごとの過去の取引の検索と、そこから同じ材料・同じ発注先に発注し直す機能は、材料・発注の画面の中に置く（別 PR） |
| ヒト | **作業員** | |
| マスタ | **取引先** | 顧客・発注先・業者名鑑を残す |

指示は2段階だった。最初は「日々の記録」を「発注」に改名して材料・発注を入れる案だったが、
続けて「材料・発注は現場の中に」と指示があった。材料・発注が抜けた後に残るのは
日報管理・出社予定・月次サマリだけなので、このグループの名前は「日々の記録」のままにする。

「取引先」は取引の相手を並べるグループなので、相手ではない積算マスタ・工種マスタの置き場所を
確認し、**設定へ移す**ことになった（利用頻度が低く管理者向けのため）。

## 決定

| グループ | 項目 |
|---|---|
| 🏠 ホーム（単独） | ホーム |
| 現場 | 入札案件 / 積算案件 / 現場管理 / 工期管理 / 現場見積もり/実経費 / **材料・発注** |
| 日々の記録 | 日報管理 / 出社予定 / 月次サマリ |
| 作業員 | **作業員一覧** / 人材評価 / 書類アラート / 人事評価3項目（役職限定） |
| 取引先 | 顧客 / 発注先 / 業者名鑑 |
| 設定 | 通知・アラート / 権限管理 / 勤怠設定 / **積算マスタ** / **工種マスタ** / AI利用状況 / AI実行ログ / 変更ログ |
| 開発 | 開発管理 / 目安箱 |

- グループ「作業員」の中の項目「作業員」は、見出しと同じ名前が並ぶと区別しにくいため「作業員一覧」にした
- 画面上部のタブ（入札・積算マスタ・業者名鑑）は変えない
- URL・権限は変えない

## 捨てた選択肢

- **「日々の記録」を「発注」に改名する**: 材料・発注を現場に移した後は、中身（日報・出社予定・月次サマリ）と名前が合わない
- **材料別の取引履歴をサイドバーの独立項目にする**: 材料・発注の画面の中に置くよう指示があった
- **積算マスタ・工種マスタを取引先に残す**: 取引の相手ではない項目が混ざり、グループ名と中身が合わない

## 影響

- 変更: `apps/core/navigation.py`（グループ名、項目の移動、「作業員」→「作業員一覧」）
- 変更: `tests/test_core_navigation.py`
- 単独のトップ項目は ホーム だけになり、グループは 6 つ（現場 / 日々の記録 / 作業員 / 取引先 / 設定 / 開発）
