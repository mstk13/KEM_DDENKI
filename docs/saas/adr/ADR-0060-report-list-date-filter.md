# ADR-0060: 日報一覧を日付（1 日）でも絞り込む

日付: 2026-09-14
状態: 採用（ADR-0047 の月の絞り込み、ADR-0050 の現場・作業員の絞り込みに足す）

## 背景

日報一覧は月（ADR-0047）でしか期間を絞れず、特定の日の日報を探すには月で絞ってから目で追う必要があった。
「月だけでなく日付も検索できるように」という要望。

## 決定

- `reports:list` に `?date=YYYY-MM-DD` を足し、`report_date` がその日の日報だけにする。
  状態・現場・作業員と組み合わせられる。読めない値（存在しない日を含む）は絞らない。
- **日付と月の両方が指定されたら日付を優先**し、月は外す（`_filtered_reports` で `month` を消す）。
  画面でも片方を選ぶともう片方を空にする（小さなスクリプト）。両方で絞ると結果が空になるか、月の意味が無くなるため。
- 日付を選んだときは「前日」「翌日」で 1 日ずつ動かす（月・年をまたいでよい）。「日付を外す」で日付だけ外す。
- 「今日」で今日の日付にする。「今月」は日付を外して今月にする。「すべての月」は月・日付を外す。
- 「現場・作業員を外す」は期間（月・日付）だけ残す（状態も外す。従来と同じ）。リンクのクエリはビューの `_filter_query` で作る。
- 件数の見出しは「2026年9月14日（月）の日報: N件」。一覧の PDF（ADR-0049）も同じ日付で絞り、
  ファイル名は `日報_2026-09-14.pdf`。

## 結果

- 日付を指定すればその日の日報だけを一覧・PDF で見られる
- 月の絞り込みは従来どおり使える
