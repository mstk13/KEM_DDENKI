# ADR-0072: 工期のガントチャートは当日から先だけを出す

日付: 2026-09-16
状態: 採用

## 背景

ホーム（`dashboard`）と工期管理（`schedules:list`・`schedules:detail`）のガントチャートは、
一番左が一番早い開始日だった。そのため過ぎた日が横に長く出て、今日どこにいるのかが読みにくかった。
プロダクトオーナーから「一番左の日付を当日から始め、日が経ったら左端も今日に更新されるように。
過ぎた日は出さないでほしい」と依頼された（2026-09-16）。

## 決定

- 画面に渡す直前で、ガントのタスクを当日から先だけに切る（`schedules.services.clip_gantt_tasks_to_today`）。
  - 終了日が昨日以前のタスクは出さない
  - 開始日が今日より前のタスクは、開始日を今日にして描く。実際の開始日は `real_start` に残す
  - ポップアップは `real_start` があればそれを使って「開始〜終了」と工期日数を出す
- 切るのはビュー（ホーム・工期比較・現場の工程）で、サービスが作るデータそのものは変えない。
  比較表の工期・日数・進捗はもとの日付のままにしたいため。
- 左端は「今日」なので、日付が変われば次に開いたときの左端も自動で変わる。
- 入札案件の「受注までの流れ」のガント（`bids.gantt`）は対象外。公告・入札の締切は過ぎた分も
  見返す必要があるため。

## 結果

- ホーム・工期管理のガントは今日から始まり、過ぎた日は出ない
- 今日より前から続いている現場・工程は、今日から右に伸びるバーとして出る（実際の開始日はポップアップで分かる）
- 終わった現場・工程・マイルストーンはガントに出ない（一覧・比較表には従来どおり出る）
