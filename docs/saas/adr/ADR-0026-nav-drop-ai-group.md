# ADR-0026: サイドバーの「AI分析」グループを撤去し、利用状況を「設定」へ移す

## ステータス

採用（2026-09-10）

## コンテキスト

システム再設計仕様書 v2.0 §7（決定②）は、AI を独立画面として置くのをやめ、
案件（現場）の文脈の中に埋め込むと決めた。実行ログ・コスト管理は
「設定 > AI利用状況」に集約する。Phase 0-4「廃止機能の畳み込み」の一部。

現状のサイドバーには「AI分析」グループがあり、3項目を持つ。

| 項目 | 画面 | 誰のためか |
|---|---|---|
| コスト分析・工程提案 | `ai:site_select`（現場を選ぶだけの中継画面） | 現場を見る人 |
| 利用状況 | `ai:dashboard`（月別・タスク別のコストとフィードバック） | 管理者 |
| 実行ログ | `ai:log_list` | 管理者・開発者 |

調べると、AI の個別機能は**すでに文脈側からリンクされている**。

| 詳細画面 | リンク先 |
|---|---|
| `sites/detail.html` | AIコスト分析・AI工程提案 |
| `costs/detail.html` | AI予測・AI最適化提案 |
| `schedules/detail.html` | AI工程提案・AIリスク分析 |

つまり「現場を選ぶ中継画面」をメニューから外しても、到達できなくなる機能はない。

## 決定

1. `NAVIGATION` から「AI分析」グループを削除する
2. 「設定」グループに「AI利用状況」（`ai:dashboard`、コストレポート・バッチ一覧を含む）と
   「AI実行ログ」を足す。v2.0 の「設定 > AI利用状況」に合わせ、設定グループ内で
   AI と分かるようにラベルへ「AI」を付けた
3. URL は変えない（v1.1 §10「既存ブックマークを変えない」）。`ai:site_select` も残す

### 個別機能を開いたときの active 表示

AI 画面を開いてもサイドバーで何も active にならないと、自分がどこにいるか分からない。
ただし「AI分析」を再び足すと本 ADR の意味がなくなる。

**そこで、個別機能はリンク元の文脈に合わせて active にする**という案を検討した
（原価系 → 現場見積もり/実経費、工程系 → 工期管理、現場選択 → 現場管理）。
これは Phase 1 の「案件詳細タブ」で自然に解決するため、本 PR では入れていない。
今は、個別機能の画面ではサイドバーのどこも active にならない。

## 捨てた選択肢

- **AI 画面の URL と中継画面を削除する**: 文脈側のボタンが残っている以上、個別機能の
  URL は必要。中継画面 `ai:site_select` は外部ブックマークの可能性があるため、
  利用ログで使われていないことを確認してから消す（v2.0 Phase 4-1）
- **「設定」ではなく「開発」に置く**: 開発グループは開発者向けで、AI のコストは
  社長・管理者も見る。v2.0 の配置どおり設定に置く

## 影響

- 変更: `apps/core/navigation.py`（グループ1つ削除、設定に2項目追加）
- 変更: `tests/test_core_navigation.py`（ラベル変更の追随と、グループ撤去の回帰テスト）
- サイドバーは 12 グループ → 11 グループ
- 権限による出し分けは変えない（AI利用状況・実行ログは従来どおり全員に出る。
  アクセスリスト方式への移行時に管理者に絞る — 要求定義 4.1）
