## 1. 必要なソフト

| ソフト | ダウンロード先 | 注意点 |
|--------|---------------|--------|
| **Python 3.11 以上** | https://www.python.org/downloads/ | インストール時に **「Add Python to PATH」に必ずチェック** |
| **Git**（任意） | https://git-scm.com/downloads | 自動アップデート機能を使う場合のみ必要 |

### 確認方法

PowerShell（Windows）またはターミナル（Mac/Linux）で:

```
python --version
```

バージョン番号が表示されればOKです。`python` が見つからない場合は `py --version` も試してください。

## 2. ダウンロード

### 方法A: GitHub Releases からダウンロード（推奨）

1. [Releases ページ](https://github.com/mstk13/KEM_DDENKI/releases) を開く
2. 最新リリースの **KEM_DDENKI-vX.X.X.zip** をクリックしてダウンロード
3. ダウンロードした zip を任意のフォルダに展開

> この方法は Git 不要です。ただし自動アップデート機能は使えません。  
> アップデートするには再度 Releases ページから最新版をダウンロードしてください。

### 方法B: Git Clone（自動アップデートを使う場合）

PowerShell（Windows）またはターミナル（Mac/Linux）で:

```bash
git clone https://github.com/mstk13/KEM_DDENKI.git
```

> Git で取得した場合、起動のたびに自動で最新版に更新されます。

## 3. 初回セットアップ

ダウンロード（または clone）したフォルダに移動して、セットアップスクリプトを実行します。

### Windows

```powershell
cd KEM_DDENKI
.\setup.bat
```

### Mac / Linux

```bash
cd KEM_DDENKI
chmod +x setup.sh start_all.sh
./setup.sh
```

### セットアップが自動でやること

1. Python 仮想環境（`.venv`）の作成
2. 全アプリの必要パッケージを一括インストール
3. 各アプリのデータベースを初期化

> **各PCで1回だけ** 行えばOKです。

---

## 4. データ共有について

全アプリのデータベースは **デフォルトでプロジェクト直下の `data/` フォルダ** に集約されます。設定は不要です。

```
KEM_DDENKI/
└── data/
    ├── bid_manager.db       ← 入札案件管理
    ├── material_manager.db  ← 材料管理
    ├── sagyo_nippou.db      ← 作業日報
    ├── evaluation.db        ← 人事評価
    └── eigyo_kanri.db       ← 営業管理
```

### 複数PCでデータを共有する方法

`data/` フォルダをネットワーク共有フォルダに変更すれば、複数PCでデータを共有できます。

`.env` ファイルを作成して `KEM_DATA_DIR` を設定してください:

```dotenv
# 例: Windows 共有フォルダ
KEM_DATA_DIR=\\192.168.0.27\kem_data

# 例: ネットワークドライブ
KEM_DATA_DIR=Z:\kem_data

# 例: Mac/Linux (NFS/SMB)
KEM_DATA_DIR=/mnt/shared/kem_data
```

データを共有する **全てのPC** で同じ `KEM_DATA_DIR` を設定してください。

> **注意**: SQLite は同時書き込みに制限があります。同時に複数人が同じアプリで書き込み操作をすると、まれにエラーが出る場合があります。少人数（5名程度まで）であれば通常は問題ありません。

## 5. アプリの起動・停止

### 起動

**Windows:** `start.bat` をダブルクリック（またはPowerShellで `.\start.bat`）

**Mac / Linux:**
```bash
./start_all.sh
```

**WSL（LAN公開モード）:**
```bash
./start_wsl.sh
```

### 起動後のアプリ一覧

| アプリ | URL |
|--------|-----|
| ポータル | ブラウザで自動表示 |
| 入札案件管理 | http://localhost:8501 |
| 材料管理 | http://localhost:5000 |
| 作業日報 | http://localhost:8502 |
| 人事評価 | http://localhost:8503 |

### 停止

- **Windows**: コマンドプロンプトのウィンドウを閉じる、または `Ctrl+C`
- **Mac / Linux**: ターミナルで `Ctrl+C`

## 6. 他のPCからブラウザでアクセスする（LAN共有）

アプリを1台のPCで動かし、他のPCからはブラウザだけでアクセスする方法です。  
この場合、他のPCにはソフトのインストールは不要です。

### 構成

```
サーバーPC（1台）                    クライアントPC（何台でも）
┌────────────────────────┐          ┌──────────────────┐
│  全アプリを起動          │          │  ブラウザだけでOK   │
│                        │          │  インストール不要    │
│  入札案件管理 :8501     │◄────────►│                  │
│  材料管理     :5000     │   LAN    │  http://サーバーIP  │
│  作業日報     :8502     │          │   :8501 等で接続   │
│  人事評価     :8503     │          │                  │
│                        │          └──────────────────┘
│  SQLite DB（全データ）   │
└────────────────────────┘
```

### サーバーPCの準備

1. 上記の手順でセットアップ・起動する
2. **Windows ファイアウォール** で以下のポートを許可する:

   - `5000`（材料管理）
   - `8501`（入札案件管理）
   - `8502`（作業日報）
   - `8503`（人事評価）

   設定方法: Windowsの「セキュリティが強化された Windows Defender ファイアウォール」→「受信の規則」→「新しい規則」→ ポート → TCP → 上記のポート番号を入力

3. サーバーPCのIPアドレスを確認:
   ```
   ipconfig    （Windows）
   ip addr     （Linux）
   ```

### クライアントPCからのアクセス

ブラウザで以下のURLを開くだけ（サーバーIPが `192.168.0.27` の場合）:

| アプリ | URL |
|--------|-----|
| 入札案件管理 | http://192.168.0.27:8501 |
| 材料管理 | http://192.168.0.27:5000 |
| 作業日報 | http://192.168.0.27:8502 |
| 人事評価 | http://192.168.0.27:8503 |

## 7. 自動アップデート

Git Clone でインストールした場合、**起動するたびに自動で**:

1. GitHub に新しいバージョンがあるか確認
2. あれば自動でダウンロード・更新
3. 新しいパッケージがあれば自動インストール
4. データベースの構造変更があれば自動適用（既存データはそのまま）

> GitHub Releases からダウンロードした場合は自動アップデートされません。  
> 最新版が必要な場合は再度 Releases ページからダウンロードしてください。

## 8. リリースの作成方法（管理者向け）

GitHub にタグを push すると、自動で Release が作成されます。

```bash
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions が自動で zip ファイルを作成し、Releases ページに公開します。

## 9. トラブルシューティング

| 症状 | 対処 |
|------|------|
| `python` が見つからない | `py` に置き換えて試す。それでもダメなら Python を再インストール（PATH にチェック） |
| `pip install` でエラー | `py -m pip install -r bid_manager\requirements.txt` を試す |
| `streamlit` が見つからない | `py -m streamlit run app.py` を使う |
| アプリのページが開かない | ブラウザで URL（http://localhost:8501 等）を直接入力 |
| 他のPCからアクセスできない | ファイアウォールでポート 5000, 8501-8503 を許可しているか確認 |
| データ共有でエラーが出る | 共有フォルダへのアクセス権限を確認。全PCから読み書きできるか確認 |
| インターネットに繋がらない | 自動アップデートがスキップされるだけで、アプリは問題なく起動・使用可能 |
