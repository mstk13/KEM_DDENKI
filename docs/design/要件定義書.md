## 1. システム概要

電気工事業向けの統合業務管理アプリケーション。以下の8つの業務領域を一元管理する。

| # | モジュール | 概要 |
|---|-----------|------|
| 1 | 日報管理 | 現場作業員の日報入力・集計・勤怠連携 |
| 2 | 原価管理 | 現場ごとの予算vs実績管理・アラート |
| 3 | 材料管理 | 見積→発注→納品→在庫の一気通貫管理 |
| 4 | 入札管理 | 案件収集→見積→入札→受注の流れ管理 |
| 5 | 工期管理 | ガントチャート・配置管理・遅延アラート |
| 6 | 人材管理 | 資格・スキル・健康診断・勤怠の統合管理 |
| 7 | 開発管理 | 開発チーム向けタスク管理・Discord/GitHub連携 |
| 8 | 取引先管理 | 顧客・発注先のマスタ・履歴・評価管理 |

---

## 2. 日報管理 (reports)

### 2.1 入力者
- **主**: 現場の作業員が自分で入力
- **副**: 事務員が作業員の代わりに入力する場合あり

### 2.2 日報の記録項目
| 項目 | 備考 |
|------|------|
| 現場 | 現場マスタから選択 |
| 作業員 | 自社＋協力会社 |
| 作業日 | — |
| 工種 | — |
| 作業内容 | — |
| 開始時間・終了時間 | 時刻ベースで記録 |
| 通常時間・残業時間 | 自動計算＋手動調整 |
| 天候 | 晴/曇/雨/雪 等 |
| 使用材料 | 欄を設ける（任意入力） |
| その他（メモ） | 旧「メモ」を改名 |

### 2.3 協力会社の管理
- 協力会社の作業員数を記録
- 協力会社の作業内容も自社側で管理

### 2.4 安全管理（KY等）
- 現場ごとにひな型（テンプレート）を登録
- 毎日、全作業員がKY等の必要書類を記入しているかを管理
- **未記入者がいればアラートを出し、記入を促す**

### 2.5 作業写真
- いったん保留（将来対応）

### 2.6 承認フロー
- 記録は残すが、承認は任意（しなくてもよい）

### 2.7 月別集計で見たいもの
- 予定工期とのずれ
- 材料のおおよその使用量

### 2.8 勤怠管理への連携
- 必要（出勤日数、有休消化、給与計算の元データ）

### 2.9 入力方法
- **スマホ** と **PC** が同等の優先度
- 写真やテキストからの貼り付け（AI自動抽出）にも対応

## 3. 原価管理 (costs)

### 3.1 閲覧権限
- **社長** と **社長が権限を与えた人** のみ閲覧可能

### 3.2 原価区分
| 区分 | 説明 |
|------|------|
| 材料費 | 材料管理モジュールと連携 |
| 労務費 | 日報の人工から自動計算 |
| 外注費 | 協力会社への支払い |
| 経費 | その他の経費 |

### 3.3 予算設定
- **現場ごと × 工種 × 原価区分** で予算を設定

### 3.4 実績の入力
- 日報から人工（労務費）を自動計算
- 材料発注から材料費を自動連携
- 上記以外は手動入力

### 3.5 アラート機能
| 閾値 | アクション |
|------|-----------|
| 75% | 警告通知 |
| 80% | 警告通知 |
| 90% | 警告通知 |
| 100%超過 | **レッド表示＋特別通知** |

### 3.6 レポート・グラフ
- 費用の推移（時系列グラフ）
- 現場ごとの費用の内訳（円グラフ/棒グラフ）

### 3.7 利益率
- 現場ごとに目標粗利率を設定可能

---

## 4. 材料管理 (materials)

### 4.1 発注フロー
```
見積依頼 → 見積取得 → 発注 → 納品 → 検収
```
全ステップ必要。

### 4.2 見積書の管理
- PDF / Excelファイルを添付して管理

### 4.3 発注書の作成
- アプリから発注書を生成（PDF / Excel対応）

### 4.4 在庫管理
- 発注・納品の記録 **＋** 在庫数の管理（両方必要）

### 4.5 仕入先の比較
- 同一材料を複数仕入先から見積もって比較可能にする

### 4.6 材料マスタ
- よく使う材料をマスタ登録し、選択式で入力

### 4.7 納品確認
- 納品日、数量チェック、検収の記録が必要

### 4.8 消化率の表示
- 現場ごとの予算vs実績の消化率を表示
- **数値＋棒グラフ等で視覚的にわかりやすく**

---

## 5. 入札管理 (bids)

### 5.1 案件の収集方法
- **手動登録**
- **Webスクレイピングで自動収集**
- **メール通知からの取込**
- 3つすべてに対応

### 5.2 AI見積もり機能
- 過去実績からの自動見積もり機能を実装
- **ローカルでオープンソースモデルを使用**（API費用高騰リスク回避）
- Claude API依存を避け、自前でモデルを運用

### 5.3 入札書類の管理
- 入札に必要な書類をアプリ上で管理

### 5.4 競合情報
- **Phase 1**: 競合の金額を記録
- **Phase 2**: 競合の強み弱み分析（将来拡張）

### 5.5 受注後の連携
- 落札案件を自動で現場管理に登録

### 5.6 ダッシュボード
- 受注率、月別件数、地域別、カテゴリ別の数値表示

### 5.7 通知機能
- 入札期限が近づいたら **メール通知 ＋ アプリ内通知** の両方

---

## 6. 工期管理 (schedules)

### 6.1 ガントチャート
- **現場単位** のバーで表示

### 6.2 配置管理
- 誰がいつどの現場にいるかを **カレンダー形式** で表示

### 6.3 マイルストーン
- 検査日、引渡日、申請期限などを管理

### 6.4 遅延アラート
- **2週間前** から警告を出す

### 6.5 工程テンプレート
- よくある工事パターンをテンプレート化して再利用

### 6.6 協力会社のスケジュール
- 協力会社の作業期間も工程表に載せる

---

## 7. 人材管理 (workers)

### 7.1 資格の期限管理
通知タイミング:
| タイミング | アクション |
|-----------|-----------|
| 1年前 | 通知 |
| 6ヶ月前 | 通知 |
| 3ヶ月前 | 通知 |
| 1ヶ月前 | 通知 |
| 1週間前 | 通知 |
| 期限切れ（更新なし） | 資格を記録から外し、該当業務不可を **本人・社長・役員** に通知 |

### 7.2 教育・研修の記録
- 受講した研修を記録

### 7.3 健康診断の管理
- 健康診断の結果を **PDFで出力** できるようにする

### 7.4 勤怠との連携
- 日報の作業時間から出勤日数を自動集計

### 7.5 スキルマップ
- 作業員ごとにできる作業の一覧を可視化
- **将来的に人員アサインの参考データとして活用**

### 7.6 拡張性
- テスト的に機能を追加しやすい構造にすること（**モジュラー設計**）

## 8. 開発管理 (devkanri)

### 8.1 アクセス制御
- **開発者のみ** アクセス可能

### 8.2 Discord連携
- タスクの通知・期限のアラートを開発者のDiscordアカウントに送信
- Discordからコマンドでタスク操作も可能（Bot）

### 8.3 GitHub連携
- PR・issueとタスクを紐づけ

## 9. 取引先管理 (masters)

### 9.1 顧客の分類
- 業種別、地域別、取引規模別に分類

### 9.2 取引履歴
- 顧客ごとに過去の現場一覧を表示（現場管理と連携）

### 9.3 発注先の評価
| 評価項目 |
|---------|
| 金額 |
| 納期 |
| 品質 |
| サービス/商品内容 |

### 9.4 名刺管理
- 名刺の写真を取引先に紐づけて保存

## 10. 横断的な要件

### 10.1 権限管理
| ロール | 概要 |
|-------|------|
| 社長 | 全機能アクセス、権限付与 |
| 役員 | 社長が付与した範囲 |
| 現場担当者 | 日報入力、工期閲覧等 |
| 事務員 | 日報代理入力、材料発注等 |
| 協力会社 | 制限付きアクセス |
| 開発者 | 開発管理モジュールのみ |

### 10.2 通知基盤
- **アプリ内通知**: 全モジュール共通
- **メール通知**: 入札期限、資格期限等
- **Discord通知**: 開発管理モジュール
- **アラート**: KY未記入、予算超過、工期遅延、資格期限

### 10.3 マルチデバイス対応
- スマホとPCが同等の操作性
- レスポンシブWebアプリ（PWA推奨）

### 10.4 AI機能
- テキスト/写真からの日報自動抽出
- 入札見積もりのAI自動生成（ローカルOSSモデル）

### 10.5 ファイル管理
- PDF/Excel添付（見積書、発注書、名刺写真等）
- PDF出力（発注書、健康診断結果等）

### 10.6 設計原則
- **モジュラー設計**: 機能追加が容易な構造
- **自動連携**: 日報→勤怠、日報→原価、材料発注→原価、落札→現場管理
- **視覚化**: グラフ・チャートによる直感的なデータ表示
