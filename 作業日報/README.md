# 作業日報管理システム

株式会社ケンモチ電機向け、電気工事現場の**作業日報**を入力・管理・分析する社内Webアプリ。
[KEM_DDENKI（入札案件管理システム）](https://github.com/mstk13/KEM_DDENKI) の構成を参考に、Python + Streamlit + SQLite で構築。

紙の「作業日報」フォームに準拠（1現場×1日で複数の自社作業員＋協力会社を1枚にまとめる形式）。
スマホでの音声入力を想定した、1件ずつ追加していく入力フォーム。

## 機能

- **日報入力**（`app.py`）: 現場名・発注先・作業日を選び、自社作業員（作業時間・残業・宿泊）と
  協力会社（会社名・人数・交通費・承認）を1件ずつ追加。作業時間は開始/終了から自動計算。
- **音声入力（スマホ）**: 「🎤」の付いた文字欄はタップしてスマホのキーボードのマイクで入力。
  追加インストール不要で iPhone / Android 両対応。
- **作業員名の漢字変換**: 作業員名を読み（ひらがな・カタカナ）で入力すると、作業員名簿の
  「よみがな」と照合して漢字の氏名に自動変換（名簿になければ入力のまま登録）。
- **日報一覧**: 期間・現場・ステータス・キーワードで絞り込み。人数・作業時間・交通費を集計表示。
- **日報詳細**: 作業員表・協力会社表・交通費合計を表示、その場で編集・削除。
- **ダッシュボード**: KPIカード（今月の総作業時間・残業時間・のべ人数・稼働現場数）と
  Plotly グラフ（日別推移・作業員別・現場別作業時間・現場別交通費）。
- **作業員管理 / 現場管理**: マスタの追加とステータス切替（作業員は「よみがな」も登録）。
- **メール通知**（`notifier.py`）: その日の日報サマリを Gmail で送信（任意）。

## セットアップ

```bash
cd nippou_manager
python -m venv .venv && source .venv/bin/activate   # 任意
pip install -r requirements.txt

python database.py     # DB 初期化
python seed.py         # （任意）デモデータ投入ですぐ試せる
streamlit run app.py   # 起動 -> http://localhost:8501
```

> メール通知を使わなければ `.env` は不要です。UI・分析だけなら `seed.py` のデモデータで動きます。

### 環境変数（`.env`／メール通知を使う場合のみ）

```dotenv
GMAIL_USER=your-email@gmail.com          # Gmail アドレス
GMAIL_PASSWORD=xxxx-xxxx-xxxx-xxxx        # Gmail アプリパスワード（16文字・2段階認証必須）
NIPPOU_EMAIL_TO=boss@example.com          # 送信先（カンマ区切り）
```

## 画面一覧（Streamlit 6画面）

| 画面 | 内容 |
|------|------|
| 日報入力 | 作業日・作業員・現場・天気・作業時間・進捗・使用資材を入力（作業時間は自動計算） |
| 日報一覧 | 期間/作業員/現場/状態/キーワードで絞り込み・総時間集計 |
| 日報詳細 | 内容表示・ステータス/進捗/内容の編集・削除 |
| ダッシュボード | KPIカード + Plotly グラフ（日別推移・作業員別・現場別・作業種別） |
| 作業員管理 | 作業員の追加・有効/無効切替 |
| 現場管理 | 現場の追加・ステータス変更 |

## データベース設計（SQLite）

| テーブル | 用途 |
|----------|------|
| `workers` | 作業員（氏名・役職・電話・有効フラグ） |
| `sites` | 現場（現場名・発注元・所在地・工事種別・着工/完了予定・状態） |
| `reports` | 日報（作業日・作業員・現場・天気・時刻・作業時間・種別・内容・進捗・申し送り・状態） |
| `report_materials` | 使用資材（日報の子テーブル：資材名・数量・単位・備考） |

- 実労働時間（`work_hours`）は `開始 − 終了 − 休憩` で自動計算。
- 金額や進捗は数値型で保存し、将来の集計・分析に備える。

## メール通知

```bash
python notifier.py                 # 本日分の日報サマリを送信
python notifier.py --date 2026-07-01
```

毎朝 cron / タスクスケジューラから呼び出せば、前日分のサマリを自動送信できます。

```bash
# cron 例（毎朝7時に前日分を送信する場合はスクリプト側で日付調整）
0 7 * * * cd /path/to/nippou_manager && /path/to/.venv/bin/python notifier.py >> notify.log 2>&1
```

## ファイル構成

| ファイル | 役割 |
|----------|------|
| `app.py` | Streamlit メインアプリ（6画面） |
| `database.py` | SQLite スキーマと CRUD（作業時間の自動計算） |
| `config.py` | 作業種別・天気・ステータス・単位・メール等の設定 |
| `notifier.py` | Gmail SMTP による日報サマリ通知 |
| `seed.py` | デモデータ投入 |
