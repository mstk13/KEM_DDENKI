# 営業訪問者 管理システム（営業管理）

株式会社ケンモチ電機向け、**営業に来た人の会社名・担当者名・営業内容を一覧管理**する社内Webアプリ。
[KEM_DDENKI](https://github.com/mstk13/KEM_DDENKI) の他アプリと同じ構成（Python + Streamlit + SQLite）。

営業担当者が持参した資料（PDF・画像・名刺）をアップロードすると、
**Claude API（claude-opus-4-8）が会社名・担当者名・事業概要・営業内容などを自動抽出**してフォームに反映。
業界・営業日は利用者が選択し、内容を確認・修正して登録します。

```
資料(PDF/画像/名刺)をアップロード → 自動抽出（Claude API）→ 確認・修正 → 登録
→ 業界→会社→記録 のドリルダウンで閲覧
```

## 機能

- **営業記録の作成**: 業界・営業日を選び、資料をアップロード → Claude API で自動抽出しフォーム入力 → 登録
- **業界から探す**: 業界一覧 → 会社一覧（事業概要付き・公式HPリンク）→ 記録 → 詳細画面のドリルダウン
- **事業概要の自動生成**: 会社HPをウェブ検索して事業概要を1〜2文で作成
- **資料の保存**: 業界/会社フォルダへ `営業日_担当者_営業要件.拡張子` で自動命名保存
- **資料プレビュー**: PDFは表紙（＋全ページ展開）を画像表示、画像はそのまま表示
- **営業一覧（全件・検索）**: 業界/状態/キーワードで絞り込み、行クリックで詳細へジャンプ
- **ダッシュボード**: 総件数・今月・要対応のKPIと業界別/状態別グラフ

## セットアップ

```powershell
cd KEM_DDENKI\eigyo-kanri
python -m pip install -r requirements.txt

copy .env.example .env      # .env を編集して ANTHROPIC_API_KEY を設定
python database.py          # DB初期化（初回のみ）
python seed.py              # （任意）デモデータ投入。APIキー不要でUIを試せる
python -m streamlit run app.py   # 起動 -> http://localhost:8503
```

> **自動抽出・HP事業概要取得には `ANTHROPIC_API_KEY` が必須**です（`.env` に設定）。
> キーが無くても、手動追加・一覧・ダッシュボード・資料の閲覧は利用できます。
> 自動再起動つきで起動するには `start_eigyo.bat` をダブルクリックしてください。

## データベース設計（SQLite）

| テーブル | 用途 |
|----------|------|
| `visits` | 営業記録（業界・会社名・担当者名・事業概要・営業内容・連絡先・公式HP・訪問日・状態・元資料パス） |

ステータス: `下書き` → `確認済` → `対応中` → `完了` / `見送り`

## 資料ファイルの保存構造

アップロード・取込した資料は、アプリの構造（業界 → 会社）に対応したフォルダへ自動保存されます。

```
data/files/<業界>/<会社名>/<営業日>_<担当者>_<営業要件>.<拡張子>
例: data/files/電材・資材/株式会社サンプル電材/20260723_山田太郎_LED照明の新製品提案.pdf
```

編集画面で業界・会社名・営業日・担当者・要件を変更すると、資料ファイルも自動で移動・改名します。

## ファイル構成

| ファイル | 役割 |
|----------|------|
| `app.py` | Streamlit メインアプリ（4画面） |
| `database.py` | SQLite スキーマと CRUD |
| `extractor.py` | Claude API による PDF/画像からの構造化抽出・HP事業概要生成 |
| `importer.py` | フォルダ監視・取込のエントリポイント（CLI/定期実行向け） |
| `storage.py` | 資料ファイルの保存先管理（業界/会社の階層へ自動命名） |
| `config.py` | ステータス・業界・フォルダ・モデル等の設定 |
| `seed.py` | デモデータ投入 |
| `start_eigyo.bat` | 自動再起動つき起動ランチャー |
