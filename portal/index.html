│       │                                                         │

│                                                                 │
│  入札管理(projects/costs) ←→ 材料管理(project/estimate/order)    │
│  同じ案件IDで連携。入札→受注→施工の全ライフサイクルを追跡        │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
データの流れ
  1. 入札管理で案件収集・見積提出
  2. 受注したら材料管理に引き継ぎ
  3. Excelで見積もり明細をインポート
  4. 発注・受領を記録し、消化率を追跡
  5. 完工後、実績データがAI学習に蓄積
  6. 次回の見積もりを自動提案
統合状況
入札管理 DBbid_manager/database.db
材料管理 DBmaterial_manager/construction.db
統合方針将来1つのDBに移行（PostgreSQL）
📖 使い方
📋 入札案件管理
  1. cd bid_manager
  2. pip install -r requirements.txt
  3. streamlit run app.py --server.port 8501
  4. ブラウザで localhost:8501

案件は自動収集（GEPS通知メール + スクレイピング）または手動追加。 見積金額・実原価・競合情報を入力して分析。

🔧 材料管理
  1. cd material_manager
  2. pip install -r requirements.txt
  3. python -c "from db import init_db; init_db()"
  4. python app.py
  5. ブラウザで localhost:5000

見積もりExcelをインポート → 発注登録 → 発注書PDFインポート → 受領書アップロード。 品目クリックで発注履歴ドリルダウン。

🛠️ 作業日報
  1. cd sagyo-nippou
  2. pip install -r requirements.txt
  3. streamlit run app.py --server.port 8502
  4. ブラウザで localhost:8502

現場名を選択 → 日付・作業員・時間・作業内容を入力 → 提出。 月次集計で稼働時間・交通費を分析。

🤖 コスト分析・AI（予定）

以下のデータが蓄積されたら開発開始:

  • 案件 50件以上 → 類似案件検索
  • 案件 100件以上 → 見積もり自動提案
  • 案件 200件以上 → 受注確率予測

今は「正確にデータを入力する」フェーズ。特にメモ欄（なぜこの金額か、どこで負けたか）が重要。

🚀 一括起動

全アプリを一括起動するには:

./start_all.sh

このポータルページは portal/index.html をブラウザで開くだけで使えます。
